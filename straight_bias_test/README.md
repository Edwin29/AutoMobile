# 트랙 없이 직진 쏠림 측정

## 구성과 실행

바닥에서 차체 바로 위 고정 카메라로 직진을 촬영한다. 기존 라인트레이서·모터 서비스가 멈춘 상태에서 파이 터미널로 실행한다. 평평하고 비어 있는 바닥에 앞쪽 1m 이상과 양옆 여유를 둔다. 책상 끝을 향해 주행하지 않는다. 기존 코드와 같은 BCM PWM 18(왼쪽), 23(오른쪽), 방향 22/27, 25/24, PWM 1000Hz를 사용한다. 모터 쪽은 각 측의 앞뒤 바퀴를 한 그룹으로 구동한다.

Windows PowerShell에서 ZIP을 파이에 복사한다. 경로는 저장한 위치에 맞춰 바꿔도 된다.

```powershell
scp "C:/workspace/AutoMobile/straight_bias_test/straight_bias_pi.zip" pi@PI_HOST:~/
ssh pi@PI_HOST
```

파이 터미널에서 실행한다. 실주행에는 파이에서 gpiozero와 lgpio를 제공하는 /usr/bin/python3을 사용하며 vcgencmd가 동작해야 한다. 모의 실행은 Python 표준 라이브러리만 사용한다.

```bash
mkdir -p ~/straight_bias_test
cd ~/straight_bias_test
unzip -o ~/straight_bias_pi.zip
python3 straight_test.py --trial A1
# 위 명령은 GPIO를 열지 않는다. 실제로 움직이는 한 번의 시험:
/usr/bin/python3 straight_test.py --trial A1 --drive
```

한 명령에 한 번만 주행한다. 정지 3초 → 양쪽 똑같이 0.5초 상승 → 양쪽 30% 10초 유지 → 0.5초 하강 → 출력 0. 전진만 하고 카메라·지도·조향 보정은 사용하지 않는다. Ctrl+C, 보드 SW1~4, 저전압·온도·스로틀·센서 읽기 오류, 제어 루프 타임아웃 때 출력을 해제한다. 갑자기 종료됐거나 차가 물체에 닿았으면 해당 영상은 별도로 표시한다.

## 촬영 방법

1. 테이프나 색종이로 앞·뒤 서로 다른 색 표식(예: 앞 노랑, 뒤 파랑)을 차체의 단단한 같은 높이 면에 붙인다. 위에서 보아 둘을 잇는 선이 차체 진행 방향과 평행하고, 간격은 가능하면 12~18cm로 한다. 두 점의 중심 간 거리를 재서 적어둔다. 바퀴·카메라·방열팬에는 붙이지 않는다.
2. 휴대폰 후면 카메라를 고정하고 바닥을 수직으로 내려다보게 한다. 가로 1080p, 30fps 이상, 일반 1× 렌즈 권장. 정지 구간부터 종료 이후까지 두 표식이 선명하고 중앙 부근에 남도록 한다. 손으로 차를 따라가지 않는다. 주행선 바깥에 바닥 기준선과 길이 기준(예: 20cm 테이프)을 두고, 바퀴가 그 위를 밟지 않게 한다.
3. 양끝을 A와 B로 표시한다. 같은 바닥 구간을 A→B, B→A로 달린다. 매번 정지한 차를 손으로 180° 돌려 반대쪽 끝에서 출발선을 향해 정렬한다. 후진 명령을 쓰지 않는다. 배터리·탑재물·노면을 유지하고 A1 B1 A2 B2 A3 B3 순서로 번갈아 찍는다.
4. 먼저 촬영을 시작하고 회차 이름을 말한 뒤 명령을 실행한다. 프로그램이 끝나고 차가 물리적으로 멈춘 뒤 2초 더 촬영한다. 가능하면 SSH 터미널의 HOLD/RAMP_DOWN 글자가 화면 모서리에 보이게 한다(확대된 터미널 창). 그러면 영상 시각과 PWM 유지 구간을 대조하기 쉽다. 터미널을 함께 찍기 어렵다면 이동 전후 순회전량을 우선 측정하고 움직임 시작으로 맞춘 유지 구간 속도는 근삿값으로 취급한다.
5. 영상은 A1.mp4, B1.mp4 등으로 저장한다. 6개 원본 또는 회차를 소리 내 구분한 연속 원본과 runs/ 폴더의 해당 실주행 로그를 전달한다. 로그 경로는 매번 출력된다. dry 모드는 모터 명령이 실제로 적용되지 않은 예행연습이다. 보정·재인코딩·메신저 압축 전 원본이 좋다.

## 로그와 판단

pwm.csv의 target_left/right는 요청 PWM, sent_left/right는 프로그램이 GPIO에 쓴 값(실제 회전수 아님), elapsed_s는 제어 시작 후 단조 시각이다. trial.json에 회차, 종료 이유, 최저 전압, 실제 유지 구간 시간이 기록된다. 전압·스로틀 상태가 다른 회차, 바퀴가 정지한 채 끌린 회차, 영상 밖으로 나간 회차 등은 정상 회차와 분리한다.

영상에서 뒤 표식→앞 표식의 각도를 프레임마다 구해 유지 구간의 각도 변화율(°/s)을 잰다. 부호는 차량 기준 오른쪽 +, 왼쪽 −다. A와 B는 차체 기준으로 비교하며 바닥 화면의 왼쪽/오른쪽 변위만으로 판단하지 않는다. A/B 각 3회의 평균과 산포를 보고, 동일 차체 방향 쏠림이 반복되는지 확인한다. 도달 위치만 옆으로 벗어나도 처음부터 차체가 비스듬했을 수 있으므로 최초 각도를 빼야 한다. 이 실험이 알려 주는 값은 이번 바닥·하중·전원에서 전진 30%일 때의 직진 쏠림이다.
