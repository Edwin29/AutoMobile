## 구조적인 원인

1. 밝기·색 임계값으로 만든 노면과 유색 영역의 접촉점이 경계다. 경계 일부가 하얗게 날아가면 실제 노면의 연속성도 끊긴다. robust는 반사율·노면 연결·노란 지지 조건을 더하지만, 작은 영역의 중요한 경계 소실은 전체 비율에서 작을 수 있고 흰 표시도 저채도·고명도일 수 있다.
2. 같은 이름으로 잡힌 경계 추적을 병합하는 수정은 효과가 있다. 다만 반대쪽 선에 대한 짝짓기에는 폭의 상한과 방향 조건이 주로 쓰인다. 적합한 최소 폭, 일관된 접선, 프레임 간 동일 경계인지 등도 함께 판단할 필요가 있다. 한쪽 선만 남으면 분기 여부와 중앙선 추정이 함께 달라질 수 있다.
3. 목표점 선택은 경로상 거리 조건을 처음 넘는 점을 택하고, 없으면 마지막 점을 택한다. 목표점이 실제 관측 범위에서 얼마나 벗어났는지, 목표 거리에서 얼마나 멀어졌는지 검사하지 않는다. 주행 코드의 robust 목표점 급변 거르기는 직선 조건에서만 동작한다.
4. `corner_mode=line`은 반경 계산 불가도 코너 종료 카운터를 올린다. 짧은 한쪽 경계와 직선 재검출을 구별해야 한다. `fixed`는 명시적인 별도 모드이며 고정 조향 중 일반 소실 정지 조건을 건너뛴다. 단독 시간 기반 주행으로 실제 회전량을 확인하기 어려운 차체다.

## 대안 시험

**기하 검사.** 길이 22cm를 넘는 목표점(기본 18cm + 추적 두 걸음)이나 실측 폭 13cm 미만(최소 도로폭 18cm − 기존 짝 허용차 5cm)을 경고로 표시했다. 같은 원본쌍에서 오른쪽 가림 큰 변화 58건 중 24건, 반사 50건 중 18건에 경고가 떴다. 왼쪽 가림은 28건 중 1건이었다. 원본에서도 184건 중 8건에 경고가 떴다. 독립 정답이 없으므로 이 경고를 오탐/정탐으로 확정하지 않는다. 즉시 대체 조향보다 관측 품질 플래그로 먼저 연결할 후보이다.

**직전 경로 기억.** 직전 원본에서 양쪽 경계·16~30cm 실측 폭·분기 없음이 확인될 때, 바닥 특징의 전후방 광류 및 RANSAC으로 직전 경로를 현재 좌표로 옮겼다. 시간 제한은 0.45초이며 현재 목표점이 2cm 이내로 일치하면 현재값을 유지한다. 유효한 원본 직전 앵커는 29쌍이었다. 가린 장면에서 미생성/추정 보류가 합성 반사 178장, 왼쪽 가림 186장, 오른쪽 가림 180장이었다. 이 결과로 연속 사각 통과 성능을 주장할 수 없다. 매 5프레임 저장본과 엄격한 앵커 조건의 한계가 포함된다. 다음 시험에서는 실제 프레임 주기로 바닥에 해당하는 특징만 쓰고, 여러 프레임 연속 소실 뒤 출구 재검출까지 확인해야 한다.

**표지판 시야.** 기존 DetectionModel 416 NCNN, 신뢰도 0.25, 클래스별 IoU 0.5 일대일 매칭으로 별도 test 52장을 검사했다. 표지·신호 라벨 72개 중 화면 오른쪽 절반 안에 전부 든 것은 54개였다. 그 54개는 전체 영상·크롭 방식 모두 검출됐다. 17개는 크롭 왼쪽, 1개는 크롭 경계에 걸렸다. 왼쪽 35%만 제외하는 넓은 입력에서는 63개가 완전히 들어오고 두 방법 모두 그중 62개를 검출했다. 라벨에는 현재 주행 지시 대상과 다른 도로의 표지판을 구분한 정보가 없다. 따라서 크롭 밖의 표지 수는 미션 실패 건수가 아니다. 회전 시 확대 검색 → 예상 접근로의 오른쪽과 시간 연속성 확인 → 방문 ID로 예약 유지가 시험할 대안이다.

## 트랙 없이 이어갈 시험

1. 동일 프레임 재생에서 여러 날짜·양방향·물리 코너를 나눠 테스트한다. 원본 목표점도 틀릴 수 있으므로 일부 프레임은 사람이 실제 경계, 추적 불가, 타 도로 표지를 표시한다. 프레임 단위 무작위 분할은 인접 사진의 중복을 과대평가할 수 있다.
2. 코너 접근 때는 맵 출구와 현재 관측을 맞추고, 회전 중에는 관측된 부분과 추정한 부분을 구분한다. 신뢰가 낮은 구간은 진행 거리·시간·허용 여유의 상한 안에서만 감속 유지하고, 예상 출구 방향과 폭이 연속 확인되어야 복귀한다. 상한을 넘으면 정지한다. PWM으로 추정한 이동량은 실측 이동량과 구분한다.
3. 검정·초록 종이로 한 모서리를 만들고 투명 파일을 얹어 스탠드 빛을 비춘다. 모터를 끈 채 실제 카메라 높이·각도를 유지하고 차를 손으로 회전한다. 광원 위치만 바꾸는 실험과 카메라 자세만 바꾸는 실험을 분리한다. 원본 영상과 촬영 시각·노출·게인을 함께 기록한다. 원본/노출 보정별 경계 유지, 경고, 위험 목표점, 올바른 출구를 다시 잡기까지의 시간을 비교한다.
4. 제동거리, 타이어 미끄럼, 안쪽 바퀴의 최소 PWM, 폐루프 완주는 저장 영상으로 검증할 수 없다.
