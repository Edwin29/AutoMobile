# 11월 10일 실차 정지 시험: 경계 조각 가중치 수정

Pi 5 + OV5647에서 모터를 움직이지 않고 실행했다. 기본 RecordingSink만 사용했고 GPIO 드라이버를 연결하지 않았다. 사용자는 위쪽 왼쪽 외곽 핑크 점선에 뒤축을 맞추고 사진 아래쪽을 향하도록 배치했다. 지도 가정상 뒤축 y=65cm, 차축 중점은 6cm 앞의 y=59cm, x=-86.25cm, yaw=π로 초기화했다. 손 배치 오차와 지도·카메라 보정 오차가 있으므로 독립 자세 정답이 아니다.

## 진단과 변경

이전 시험에서 정지한 차의 추정 위치가 흔들렸다. 추정기에 가상의 주행 명령을 넣은 것은 아니다. 시험 스크립트는 처음부터 `shadow_pwm=[0,0]`을 전달했다. `predicted_v`는 제안 명령이며 실제 적용 명령과 구분해야 한다. 40프레임 동안 가설 수는 1개였다.

저장 원본 4장 분석에서 가까운 긴 경계는 안정적이었지만 먼 쪽 1~2cm 조각들의 구성이 달라졌다. 기존 조각별 1/√N 가중치는 짧은 조각과 긴 조각의 총 제곱 가중치를 같게 만들었다. 첫 사진의 짧은 조각 하나를 진단용으로 제외하자 동일 prior의 정합 잔차가 2.33cm에서 0.18cm로 줄었다. 해당 조각이 허위 관측인지 실제 경계의 잘못된 지도 대응인지는 확정하지 않았다.

수정 사항:

- 관측 호길이에 비례한 가중치. 6cm를 단위 지지량으로 사용한다.
- 인접하고 방향이 일치하는 조각은 지지 길이를 공유한다. 틈을 관측 길이에 추가하거나 가상 경계점을 만들지 않는다.
- 고립된 지지 길이가 4cm 미만이면 `min(1,L/4)^2`로 영향력을 연속 감쇠한다. 짧은 조각을 일괄 삭제하지 않는다.
- 겹치는 표본의 중복 영향력을 공간 셀로 제한한다. 단순 분할이나 복제로 증거가 여러 배가 되지 않도록 시험한다.
- Huber의 전환점을 가중 후 잔차가 아닌 물리 잔차에 적용한다. 가중치가 작다고 이상치 허용 거리가 커지는 문제를 방지한다.
- 잔차 판정도 동일한 증거 가중치를 사용하고, 원래 비가중 잔차를 별도로 기록한다. 가중 잔차 감소만으로 정확도를 주장하지 않는다.

4cm/6cm 및 연결 거리·각도는 초기 비교용 값이다. 통계적으로 보정된 확률이나 다른 장면의 최적값이 아니다. 전방의 짧은 조각을 억제하면 실제 코너·교차로 단서도 약해질 수 있으므로 주행 검증이 필요하다. Q, 거리장 차감, 경로 허용 기준, 초기 공분산, 카메라 노출은 이번에 바꾸지 않았다.

## 실제 Pi 정지 시험

`stationary_20261110_173903`에 원본 40장과 타임스탬프·카메라 metadata·정합·경로 판정·명령 로그를 저장했다. 카메라 설정은 640×480 RGB888, 소프트웨어 180도 회전, queue=False, 30fps 요청이다. 기존 보정을 사용하며 현재 장착 각도/센서 crop 일치는 독립 검증되지 않았다. YOLO는 실행하지 않았다.

- 40/40 프레임 정합, 경로 tracking 26회 / no_feasible_candidate 14회.
- 첫 호출 약 695ms. 거리장 등의 최초 초기화 비용이 포함된다.
- 최초 3프레임 제외: 전체 처리 중앙값 83.6ms, p95 115.0ms.
- 센서 timestamp부터 결과까지 중앙값 100.4ms, p95 131.9ms. 광자 입력부터 실제 모터 반응까지의 지연이 아니다.
- 추정기에 실제 전달된 속도/각속도를 계측해 전 프레임 (0,0)을 확인했다. 소프트웨어에 선언한 PWM=0만 확인한 것이 아니다.

## 같은 40장·같은 Pi 환경에서 A/B 재생

두 설정 모두 초기 자세와 영상·촬영 시각·실행 시각을 같게 하고 적용 운동은 0으로 고정했다. 실제 출력은 없다. 수치는 후반 20프레임의 최대−최소 폭이며 절대 위치 오차가 아니다.

| 지표 | 기존 조각 동일 가중치 | 관측 길이 가중치 |
|---|---:|---:|
| 좌우 위치 변동 폭 | 0.883cm | 0.134cm |
| 앞뒤 위치 변동 폭 | 3.168cm | 0.246cm |
| yaw 변동 폭 | 1.413° | 0.429° |
| 정합 통과 | 40/40 | 40/40 |
| 경로 tracking / 보류 | 3 / 37 | 26 / 14 |

정합 통과 수는 같아도 추정 안정성과 경로 결과는 다르다. 수정판의 최종 추정은 초기값에서 x 약 +2.73cm, y 약 −3.83cm 바뀌었다. 이 변화가 배치 오차를 정확히 고친 것인지는 확인되지 않았다. 처음과 끝이 같은 실제 자세라는 조건은 시간적 안정성을 검사할 뿐 절대 위치 정답을 제공하지 않는다.

노트북에서 같은 자료를 재생했을 때에는 수치가 달랐다. Pi의 OpenCV 5.0.0 / NumPy 2.2.4 / SciPy 1.18.1과 노트북 환경이 다르며, 약한 정합 방향의 수치 민감성을 추가 검토해야 한다. 위 표는 Pi끼리 비교한 결과다.

## 검증과 남은 문제

자동 시험 62개 통과. 추가한 5개는 조각 분할, 짧은/긴 조각 복제, 짧은 고립 조각의 영향, 틈을 지지 길이에 더하지 않음, Huber 전환점과 가중치 분리를 검사한다.

실제 주행은 하지 않았다. 수정 후에도 최종 6cm 후보 검사에서 곡률 제한으로 탈락하는 경로 보류가 남았다. 긴 후보가 먼저 탈락한 원인은 단계별 로그를 더 남겨 구분해야 한다. 이것을 모두 거리장 오차나 정합 실패라고 부르지 않는다.

재생 명령:

```powershell
python -m drive_v3.replay_stationary <정지_기록_폴더> --output <새_결과_폴더>
```

입력에는 `steps.jsonl`, `manifest.json`, 모든 `NNN_raw.png`가 필요하다. 자세 정확도나 폐루프 주행을 검증하는 도구가 아니다. [Pi 동일 입력 비교 근거](../drive_v3/evidence/stationary_weighting_20261110.json)에 입력 해시·코드 해시·수치를 보관했다. 원본 영상과 개별 로그는 로컬 및 Pi의 별도 시험 폴더에 보존했다.
