# 세 번째 주행 프로그램 설계

2026-11-10 사용자와 합의한 여섯 파트의 선택안이다. C안의 국소 관측과 기존 월드모델의 형상·사각 보완을 결합한다. 예측이 틀릴 수 있음을 전제로 관측·지도 예상·미확인을 구분한다. 이 문서는 구현 목표이며, 구현 및 검증 상태는 [drive_v3 README](../drive_v3/README.md)에 별도로 기록한다.

## 공통 원칙

- 기존 C안·월드모델·원본 로그는 보존하고 `drive_v3/`에 별도 구현한다. Pi 배포나 모터 실행은 이번 로컬 구현에 포함하지 않는다.
- 통계 분석을 선행조건으로 두지 않는다. 설명 가능한 임시값으로 시작하고 설정·선정 이유·변경 전후 결과를 남긴다. 임시 점수는 보정된 확률이 아니다.
- 정합 통과, 저장 영상 재생, 합성 시험, 실차 폐루프 성공을 구분한다. 실차 연속 자세 정답은 아직 없다.
- 추정한 경계를 관측으로 다시 넣지 않는다. 같은 영상에서 얻은 VO·경계·표식의 상관성을 무시해 증거를 중복 집계하지 않는다.
- 위치 보정량과 실제 이동량을 분리한다. 보정만으로 미션 통과·새 방문을 선언하지 않는다.
- 자동 이탈 복귀는 관측 가능한 공간과 동작 여유를 검사한다. 무조건 계속 주행하거나 자동 후진하는 구조는 채택하지 않는다.

## 1 관측부

| 문제 | 선택 | 적용 |
|---|---|---|
| 영역 구분 | HSV | 도로·초록/노랑·파랑·핑크·빨강·흰색의 후보 마스크 |
| 바닥 좌표 | 기존 렌즈 보정 + BEV | 해상도·180도 회전·보정 여부를 명시적으로 지정 |
| 조각화 | 연결 성분 보조 + 선 추적 개선 | 분기·끊김에서 관측 조각을 분리하고 연결 후보를 별도 저장 |
| 경계 의미 | 방향·양옆 노면 관계 | 좌우는 후보이며 불명확하면 unknown |
| 표식 | 색 + 형태·배열 규칙 | 핑크 점선·빨간 실선·횡단보도 후보 |
| 파란 원 | 색 + 원호 형태 | BEV에서 중심·크기 추정. 부분 가림의 픽셀 평균을 원 중심으로 사용하지 않음 |
| 표지판·신호등 | 비전팀 YOLO 어댑터 | 우측 영상 영역, 지원 클래스와 모델 버전 확인 |
| 일관성 | 시각 기록 + 반복 관측 | 이전 관측과 현재 관측을 구분 |

출력은 경계 조각, 연결 후보, 표식/원 후보, 표지 인식, 품질 근거, 관측 공백, 촬영 시각이다. 빈 영상은 좋은 관측이 아니라 관측 부족이다. 밝고 저채도인 곳은 반사 가능성이지 반사 확정이 아니다. 높은 물체의 윤곽에는 바닥 호모그래피가 성립하지 않는다.

지도 보완은 이 파트에서 하지 않는다. 큰 연결 성분 두 개만 선택하지 않는다. 분기 창 안의 두 경계를 평균하지 않는다. 끊긴 선을 연결한 그림을 완전히 관측된 선처럼 내보내지 않는다. 초기 구현은 skeleton의 연결 관계를 추적해 분기와 공백을 보존한다. 이는 C안 추적의 개념을 계승하지만 창 중심 평균 및 무표시 gap 연결을 그대로 복사하지 않는 구현 결정이다.

적응형 임계값·RoadNet·편광 필터·전체 허프/RANSAC 경계 추출은 비교 대안으로 보류한다. 기존 9종 YOLO에는 직진·좌회전 클래스가 없어 전체 미션 지원을 가정하지 않는다.

## 2 지도와 기준 경로

| 역할 | 선택 |
|---|---|
| 연결 | 방향 있는 구간 그래프, 진입로별 출구 |
| 원본 형상 | cm 좌표 경계선과 주행 가능 영역 |
| 계산 보조 | 도로 마스크와 SDF, 경계 ID 유지 |
| 랜드마크 | 핑크선·빨간선·횡단보도·파란 원 ID와 위치·크기·소속·불확실성 |
| 경로 | 중앙선 기반 후보 생성 → 차체 검사 → 평가·제한적 최적화 |
| 곡선 | 3차 B-스플라인, 접합·곡률 조건 검증 |
| 차체 여유 | 윤곽 쓸림 검사와 (s,d,psi)별 여유표 |
| 지도 오차 | 실측/사진 추정 구분, 불리한 경계 변형 시험, 버전 |

중앙선이 최종 최적 경로라고 가정하지 않는다. 진입/출구별 경로를 계산하는 것은 코너별 임의 PWM 계수를 추가하는 것과 다르다. 미리 검증한 경로에서 벗어난 실제 자세와 변형한 경로는 다시 검사해야 한다. 이산 샘플 사이의 침범과 SDF/표 해상도 오차를 고려한다. 불가능한 경로는 불가능으로 남긴다.

차체 앞끝에서 14.5cm를 좌표 기준점으로 사용한다. 전장 약 24.5cm, 폭 약 16cm이며 기준점이 실제 순간 회전 중심이라는 뜻은 아니다. 도로폭은 외곽 26/24cm, 내부 21/18cm 기록이며 해당 지도 축·배치 확인이 필요하다. 파란 원 좌표와 크기는 아직 독립 실측 정답이 아니다. 기준 경로와 계산 자료는 노트북에서 생성한다.

## 3 상태 추정

| 역할 | 선택 |
|---|---|
| 예측 | 실제 전달 PWM과 시간에 따른 운동 모델, 이동 불확실성 증가 |
| 상대 이동 | 품질 검사한 노면 특징 VO |
| 대응점 이상치 | VO에서 RANSAC |
| 지도 정합 | 종류·구간·방향을 구분한 거리장/랜드마크 정합 |
| 강건화 | Huber 로스 |
| 필터 | 주 가설 EKF, 필요한 경우만 대안 가설 유지 |
| 불일치 | innovation 및 마할라노비스 검사 |
| 복구 | 거친 탐색 후 정밀 탐색, 필요시 인접 구간 |
| 적응 | 관측 가능한 조건에서 운동계수를 천천히 갱신 |
| 정체 | 움직임 확인 / 정체 의심 / 판단 불가 구분 |
| 시간 | 촬영 시각의 보정 후 명령 이력으로 현재까지 재예측 |

내부 자세는 x,y,theta, 구간별 s,d,psi는 파생한다. 후보는 구간·자세·공분산·대응·지지 근거를 묶은 자료다. 단순 앞뒤 오차는 한 후보의 범위로 표현한다. 같은 원의 다른 ID 대응처럼 의미 있는 충돌에만 분기한다. 모든 경우의 수를 전개하지 않고 후보 병합·제거·수 제한·모호함 지속시간 평가를 둔다. 예측 후보와 관측 후보를 무조건 독립 확률로 곱하지 않는다.

점수는 정규화 잔차, 지지 관측 범위·배치, 다른 후보와의 차이, 자세 변화에 대한 관측 민감도로 평가한다. 한 경계의 많은 픽셀을 독립 증거로 세지 않는다. 유리한 점만 선택한 후보를 보상하지 않는다. 낮은 최저 잔차가 정확한 자세의 증명은 아니다. s를 언제나 고정하거나 표식에서만 갱신하도록 제한하지 않고 관측 가능한 성분을 갱신한다.

마할라노비스 게이트 밖의 관측이라도 여러 단서가 일관되면 재탐색한다. 잘못된 prior 때문에 정상 관측을 전부 거부하지 않는다. RANSAC·강건 로스도 일관된 가짜 경계를 의미적으로 판별해 주지는 않는다. 공분산·게이트는 초기 실험값이며 정답 보증이 아니다. UKF/MCL/factor graph는 비교 대안이다.

## 4 경로 결정

| 역할 | 선택 |
|---|---|
| 상태 | FSM: 추종·교차로 접근·회전·출구 정렬·재관측·복귀 |
| 정보원 | 관측 공간 제약과 지도 형상 보완 |
| 안정화 | 규칙·히스테리시스, 명확한 위험은 즉시 대응 |
| 국소 계획 | 기준·합류·좌우/회전시점 조정·조건부 관측 스플라인 후보 |
| 불확실성 | 유지된 후보에서 공통 허용 행동 + 명시 오차 범위의 불리한 조건 검사 |
| 검증 | 차체 쓸림, 추종 가능성, 정지 여유, 미션 조건 |
| 복귀 | 도로 내 합류, 재관측, 조건부 이탈 복귀 |

현재 차체 자세에서 출발하는 동일한 차량 기준 경로·속도를 각 위치 후보에서 검사한다. 후보마다 다른 안전 경로가 있다는 것만으로 실행 가능한 공통 명령이 존재한다고 판단하지 않는다. 지도/관측 조향 평균은 사용하지 않는다. 완전한 lattice/DWA/MPC는 현재 주 방식이 아니다.

출구 확정과 회전 시작, 회전 완료를 분리한다. 출구는 유지하되 세부 경로는 계속 갱신한다. 완료는 타이머만으로 결정하지 않는다. 이탈 복귀는 시작 침범 때문에 모든 후보를 무조건 탈락시키는 일반 검사와 구분하되 추가 침범·쓸림·확인 가능한 공간을 평가한다. 기본 자동 후진/제자리 회전은 없다.

출력은 경로, 권장 속도/상한, 유효 범위/시각, 선택·불가능 사유다. 낮은 속도가 공간적으로 불가능한 경로를 가능하게 만들지는 않는다.

## 5 주행 제어

| 역할 | 선택 |
|---|---|
| 주 추종기 | 곡률 피드포워드 + 위치/방향 오차 피드백 |
| 비교 | 같은 경로·PWM 조건에서 pure pursuit |
| 속도 | 곡률·오차·관측 품질 제한 + 가감속 프로파일 |
| 출력 모델 | 좌우 PWM 조합과 시각으로 추정한 차체 반응 |
| 데드밴드 | 작동 범위 검사와 좌우 공동 조정 |
| 출력 변화 | slew rate 제한, 실제 전달 명령 기록 |
| 지속 쏠림 | 0에서 시작하는 동적 trim + anti-windup |
| 지연 | 현재 시각 상태와 제한된 preview |
| 적응 | 추정·출력 변환이 공유하는 반응 모델의 느린 갱신 |

이상적인 정렬 상태에서 omega=v*kappa를 출발점으로 사용한다. 이를 pure pursuit 회전량에 무조건 중복 가산하지 않는다. 엔코더 없는 상황에서 PWM 표를 바퀴별 실측 속도표로 부르지 않는다. 초기 좌우 묶음 출력, 바퀴별 보정은 별도 근거가 필요하다.

한쪽 PWM만 최소값으로 올리지 않는다. 최종 제한 후 예상 움직임이 요청과 다르면 재검사하고 불가능 상태를 상위에 반환한다. 정지는 최소 구동 보상에서 제외한다. 출발 킥은 기본 비활성이다. 일반 감속과 긴급 정지를 구분하고 실제 제동 특성은 검증한다.

trim은 신뢰 가능한 지속 편향에만 천천히 적응한다. 정체·포화·관측 부족·큰 재위치 보정 중에는 적분을 멈추며 크기/변화율을 제한한다. 반응 모델 갱신과 trim이 중복 보상하지 않도록 관리한다. 순간 슬립을 영구 계수로 흡수하지 않는다. Stanley/LQR/MPC/Smith predictor는 비교·확장 대안이다.

## 6 미션 관리

| 역할 | 선택 |
|---|---|
| 흐름 | 계층형 FSM, 등록·준비·실행·완료·충돌·실패·기한초과 |
| 전달 | 촬영 시각·대상·구간·방문 ID를 가진 이벤트 큐 |
| 예약 | 대상·거리·상태 조건, 단순 FIFO/고정 시간만 사용하지 않음 |
| 중복 | 디바운싱 + 방문 ID + 실행 이력 |
| 영상 대상 | SORT 계열을 보조로 사용, 영구 지도 ID와 구분 |
| 마지노선 | 행동별 지연·필요 이동량·불확실성 |
| 충돌 | 우선순위와 기한 있는 재확인 |
| 통과 | 물리 이동과 위치 보정 분리 |

방향 표지는 해당 갈림길 방문에 연결한다. STOP/SLOW/HORN은 핑크 점선 전까지 요구 동작을 수행한다. 중앙 사거리의 해당 진입 횡단보도에서 빨간 신호 정지 조건을 적용하고 우회전 목표를 유지한다. 외곽 횡단보도는 위치 단서와 중앙 신호 미션을 구분한다. 빨간 선은 출발/단계 규칙에 연결한다. 랜덤 표지 내용은 지도에 고정하지 않는다.

거리 판단의 기본은 남은 거리 <= 속도*남은 지연 + 필요한 이동량 + 여유다. 차량에서 먼저 닿는 윤곽을 기준으로 하며 카메라 지연을 중복 가산하지 않는다. STOP 정지거리, SLOW 감속거리, HORN 수행시간을 구분한다. 정지 유지시간·재출발 신호·경적 길이 등의 미확정 규칙은 임의로 확정하지 않는다.

명령 전달과 실제 완료를 구분한다. 추적 ID 재발급만으로 같은 미션을 재실행하지 않는다. 위치 보정만으로 선 통과·방문 증가를 선언하지 않는다. 보류는 재확인 기한이 있고 해결되지 않으면 정지/실패로 명시한다.

## 파트 간 규약

공통 단위는 cm, 초, rad다. 차체 평면 좌표는 x=오른쪽, y=전방, theta는 북쪽 전방을 0으로 시계방향 양수인 기존 지도 관례에 맞춘다. 좌우 오차의 부호는 각 경로 접선 기준으로 명시한다. 영상은 BGR, 해상도 (width,height), 배열은 (height,width,channels)다. 180도 회전 여부와 렌즈 보정 여부는 입력마다 명시한다.

촬영 timestamp는 원본 단조 시계 값과 clock ID를 함께 전달한다. 저장 영상의 재생 시각·파일 순서·센서 시각을 혼동하지 않는다. 다른 시계의 차이를 지연이라고 계산하지 않는다. 모든 결과에 설정·보정·입력·코드 해시와 실행 종류를 남긴다.

관측부 → 상태추정부: 실제 관측/품질/촬영 시각. 지도부 → 상태/경로부: 형상/대응/기준 경로. 상태부 → 경로/제어/미션부: 위치 후보/불확실성/이동. 미션부 → 경로/제어/부저: 목표와 제약. 경로부 → 제어부: 실행 경로와 유효기간. 제어부 → 상태/경로/미션: 실제 전달 PWM과 실행 상태.

최종 모터 명령은 제어부의 단일 경로를 거친다. 입력 누락·오래된 경로·프로세스 종료 시 출력 정책을 명시한다. Pi 구동 전에는 watchdog·정지 방식·GPIO 소유권을 별도로 검증한다. 미션부가 제어 주기를 막거나 PWM을 별도로 덮어쓰지 않는다.

## 구현과 검증 순서

1. 독립 폴더, 데이터 규약, 설정과 출처, 오프라인 관측 재생 도구.
2. 관측 조각·분기·공백·파란 원 검증, 바닥 표식 묶기와 비전 어댑터.
3. 지도 어댑터·랜드마크 좌표 검토·기준 경로/차체 검사.
4. 상태 추정·VO·후보/공분산·시간 처리, 고정 관측 재생.
5. 후보 경로와 제어, 실제 관측 실패 및 운동 편차를 포함한 폐루프 합성 비교.
6. 미션 FSM과 실행 어댑터, 모의 이벤트·중복·기한·충돌 시험.
7. Pi 성능·출력 검증을 거쳐 별도로 승인된 실차 시험.

검증은 완주뿐 아니라 침범, 최소 여유, 잘못된 대응, 불필요한 정지, 모호함 지속시간, 복귀, 마지노선 위반, 지연을 기록한다. 저장 영상 재생은 새 제어기의 실차 폐루프 성능을 입증하지 않는다. 원본 실차 라벨의 검수 상태와 알려진 회귀 장면/새 검증 장면을 구분한다.
