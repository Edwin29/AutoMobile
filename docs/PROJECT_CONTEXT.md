# 프로젝트 맥락과 설명 정정

작성일 2026-11-09. 근거는 이 채팅에 포함된 사용자 관찰, 노트북의 소스 스냅샷과 결과 파일이다. Pi의 현재 배포본은 이번 정리에서 조회하지 않았다.

## 다른 에이전트에게 전달할 설명

라즈베리파이 5와 OV5647 단안 카메라를 사용하는 4륜 소형 차량으로, 크기와 도로폭이 비대칭인 田자 트랙을 주행하는 과제다. 바퀴 엔코더와 자이로가 없다. 저장된 구동 코드는 좌우 PWM 듀티와 방향 핀을 제어한다. DC 기어모터 구동과 일치하는 구성이고, 스텝모터라고 확인할 모델명이나 스텝 수 측정은 없다. 모터의 정확한 제품명과 앞뒤 바퀴별 독립 제어 배선은 추가 확인 대상이다.

주행에서 관찰된 문제는 같은 PWM을 줘도 왼쪽으로 휘는 경우, 낮은 출력에서 바퀴가 늦게 움직이거나 멈추는 경우, 회전 시 밀림과 미끄러짐, 배터리 상태에 따른 전원 중단이다. 완충 뒤 같은 시험에서 전원 중단이 재현되지 않았지만 전압 강하가 원인이었다고 계측으로 확정하지는 못했다. 모터 명령은 실제 바퀴 속도나 실제 차량 이동량을 측정한 값이 아니다.

팀원의 기존 C안은 색 대비로 도로 경계와 국소 경로를 만들고 조향한다. 별도 연구 코드에서는 가상 맵, 카메라 보정과 차량 기준점을 사용한다. PWM으로 다음 자세를 예측하고, 카메라에서 추출한 도로 경계를 바닥 좌표로 투영한 뒤 지도 경계까지의 거리를 줄이도록 자세를 보정한다. 수정된 자세에서 지도 경로의 전방 목표점으로 조향한다. 매 프레임 영상 전체를 렌더링해 픽셀 단위로 비교하는 것이 현재 외곽 제어기의 구현은 아니다.

카메라와 맵에는 실측값·캘리브레이션 결과·가정이 섞여 있다. 촬영 세션마다 장착 자세와 전처리 일치 여부를 확인해야 한다. 차체 앞뒤 차축 중점은 앞끝에서 약 14.5cm이며, 미끄러지는 동안의 실제 순간 회전 중심과 구분한다. 독립적인 연속 실차 위치 정답은 확보하지 못했다.

회전 예측계수와 출력 보상계수는 별도다. 표식의 상대 각도 변화와 PWM 예측 회전량의 비율로 예측계수를 갱신하는 코드가 있다. 출력 보상에는 지도 보정 자세의 변화량을 쓰는 실험판도 있다. 실제 정지 직전 로그에서는 영상 오검출뿐 아니라 지도 정합의 즉시 거부와 불확실한 종방향 위치가 주행을 제한했다.

직선의 평행 경계만으로는 앞뒤 위치를 잘 구분할 수 없다. 하지만 횡단보도, 점선, 코너 접속부와 텍스처는 추가 단서가 될 수 있다. ±5cm 후보 실험은 모든 후보가 현재 허용 조건을 통과했다는 결과이며, 영상에 종방향 정보가 전혀 없다는 증명은 아니다.

표지판 인식은 별도 팀이 맡는다. 확보한 YOLO의 9개 클래스는 cross, dashline, green, horn, line, red, right, slow, stop이다. 직진·좌회전 방향 표지가 빠져 있으므로 전체 미션 통합이 완료됐다고 가정하면 안 된다. 별도 RoadNet은 합성 영상으로 도로·도로 밖·가림 물체를 분류한 첫 실험 모델이며 실차 학습이나 검증된 실차 완주 모델이 아니다.

## 원 설명에서 수정할 문장

| 원 표현 | 확인한 사항과 권장 표현 |
|---|---|
| 동일 PWM 기반 스텝모터 4개 | 동일 명령을 줬다는 관찰과 동일 회전 속도는 구분해야 한다. 코드에는 스텝 펄스 제어가 없고 좌우 듀티·방향 제어가 있다. DC 기어모터 추정, 정확한 모델 미확인으로 표현 |
| 센서가 전무 | 주행 피드백에 단안 카메라를 사용하고 바퀴 엔코더·IMU가 없음. 전원 진단 로그와 버튼 입력은 별도로 존재 |
| 표지판 인식은 잘 됨 | 별도 팀 담당. 본 기록에서 전체 클래스·실차 미션 통합 성공률은 확인하지 못함 |
| 맵과 내외부 파라미터를 전부 앎 | 일부 실측 및 세션별 보정 추정값이 있음. 인쇄·배치·카메라 자세 오차, 사진과 지도 축 대응이 남아 있음 |
| 지형지물의 상대 위치 변화로 현재 위치 추정 | 외곽 Driver는 현재 프레임 경계와 지도 정합을 사용. 상대 표식 추적은 GainTracker가 별도로 사용 |
| 동적 계수로 좌우 회전 강도를 보상 | 예측계수와 출력계수가 별개이고 실행 옵션별 활성 상태가 다름 |
| 직진 5cm 차이로 현재 위치 오인이 생김 | 평행 경계의 종방향 제약이 약함. 후보 판정 통과 실험에는 실측 자세 정답이 없으므로 실제 오인 크기를 확정할 수 없음 |

## 과제 규칙

- 표지는 주행 방향의 오른쪽에 배치된다. 방향 표지는 교차로에서 실행할 직진·좌·우 선택으로 보관한다.
- STOP·SLOW·HORN은 핑크 점선이 실행 트리거이자 마지노선이다. 처리 지연과 정지거리를 포함한 선행 실행 필요량은 별도 검증해야 한다.
- 중앙 사거리에 진입하면 우회전이 요구된다. 빨간 신호에서는 해당 진입로 횡단보도 앞에 정지한 뒤 규칙에 따른 우회전 절차를 수행한다. 정지 시간·신호 재개 조건은 최신 평가 규칙으로 확인한다.
- 외곽 횡단보도는 그 신호 정지 임무의 대상에서 제외하지만 위치 단서로는 사용할 수 있다.
- orchestration 설계와 가상맵 외곽 실험판, 팀원의 주행 프로그램은 별도 구현 단계다.

## 물리 치수와 불확실성

| 항목 | 현재 기록 |
|---|---|
| 차체 전장 | 최종 사용자 정정 약 24.5cm. 초기 26cm와 구분 |
| 바퀴 포함 폭 | 약 16cm. 초기 15.5cm 관측도 있음 |
| 앞·뒤 차축 | 앞끝에서 약 8.5cm, 20.5cm. 중점 14.5cm, 축간 12cm |
| 차체 길이 중점과 축 중점 | 12.25cm와 14.5cm. 차이 2.25cm |
| 트랙 | 사진 실측 외곽 26/24cm, 내부 21/18cm. 지도 축·129/133cm 측정 끝점은 measurements.photo.json 및 기존 설계 문서 참조 |
| 카메라 | OV5647. 촬영 640×480, 장착 때문에 180° 회전한 저장 영상. 렌즈 보정과 바닥 투영의 세션별 대응 필요 |
| 런타임 차체 모델 | 직사각형 및 사진 윤곽 버전이 모두 존재. 실제 회전 중 쓸림과 바퀴 지연을 완전 재현하지 못함 |
