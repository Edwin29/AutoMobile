# 가상맵 외곽 주행 실험판

라즈베리파이 5와 기존 OV5647 카메라용. 왼쪽 외곽 횡단보도 중앙에 차체의 길이 중점을 두고 도로 중앙에 평행하게 놓는다. 사진에서 왼쪽 아래 코너로 출발하면 ccw, 위쪽으로 출발하면 cw다. 다른 시작점, 중앙 교차로·미션 주행은 이번 판의 검증 범위 밖이다.

## 실행

압축을 별도 폴더에 풀고 그 폴더에서 실행한다. 기존 서비스가 카메라와 GPIO를 점유한다면 먼저 종료한다. 기존 프로젝트 설정·자동 실행 항목을 바꿀 필요는 없다. 시스템 Python이 picamera2, cv2, numpy를 제공해야 한다. 모터 출력에는 gpiozero, vcgencmd가 추가로 필요하다.

먼저 출발 위치에서 정지한 채 카메라와 지도 정합을 확인한다. 이 모드는 GPIO를 열지 않고 제안 PWM과 실제 적용 PWM(0)을 서로 다른 열에 기록한다.

```bash
python3 run_pi.py --direction ccw --duration 8
```

아래 명령은 실제 바퀴를 움직인다. GPIO와 버튼, 전압 측정, 카메라 방향을 실제 장치에서 점검하고 통제된 트랙에서 짧게 시험할 때 사용한다. 현재 실기 주행과 정지거리는 미검증이다.

```bash
python3 run_pi.py --direction ccw --duration 3 --drive
```

Ctrl+C 또는 보드 버튼으로 종료한다. 종료 후 재시작하려면 알려진 출발 위치에 다시 놓는다. 매 실행마다 현재 폴더의 map_run_*.csv에 자세, 지도 경계와 관측의 중앙 오차, 예상 차체 최소 여유, 요청 및 적용 PWM을 기록한다. reason이 footprint limit이면 추정 차체 여유 부족, unmatched road edges이면 영상과 지도의 경계 정합 실패다. 실제로 어디를 넘었는지는 이 로그만으로 측정할 수 없다.

## 동작과 가정

계산 단위는 cm다. 지도에서 x는 동쪽, y는 북쪽, yaw는 북쪽 기준 시계방향이다. 카메라는 차축 중점보다 12.36cm 앞에 있고, 앞·뒤 차축은 차체 앞끝에서 각각 8.5cm와 20.5cm로 두었다. 속도는 좌우 대칭 선형 모델(최대 출력 단위당 16cm/s), 바퀴 간격 13cm를 가정한다. 물리적 미끄러짐·구동 지연은 모델에 포함하지 않는다.

640×480 RGB888 카메라 영상을 차체 장착 방향에 맞게 180° 회전하고 어안을 보정한다. 기존 검출 방식에서 얻은 노면-유색 경계점을 이전 PWM으로 예측한 자세 근처의 지도 경계에 맞춘다. 직선에서 전후 위치가 모호하므로 출발 위치가 중요하다. 지도 경로의 10cm 앞 목표점을 향해 조향한다. 차체 전체를 0.25cm 간격으로 표본화해 현재·0.15초·0.30초 뒤 여유를 평가한다. 정합 실패, 경로 급변, 여유 부족, 오래된 프레임, 저전압 등은 정지로 처리한다. 독립 타이머가 응답 지연을 검사하지만 물리적인 비상정지장치를 대신할 수 없다. 시험용 여유·시간 기준은 실측된 제동거리가 아니다. 사용되는 지도 단서는 도로 경계이며 표지와 신호등에 대한 임무 처리는 포함하지 않는다.

## 확인한 결과

이상적인 가상 폐루프에서 카메라 프레임, 이전 적용 PWM과 지정 출발 자세만 사용해 외곽 양방향 1바퀴를 돌았다. 정답은 별도로 채점에만 썼다. 시계·반시계 최소 여유 약 0.53cm, 반시계 출발점이 옆으로 1cm 어긋난 경우 약 0.54cm. 전백색 프레임 주입 시 해당 스텝에서 정지 명령. 실제 저장 JPEG/당시 PWM의 순방향 재생에서는 55번 프레임(3.655초)에서 정합 실패로 정지했다. 실차 폐루프 완주 성능과 Pi 처리 지연은 아직 측정하지 않았다.

## 표식을 이용한 동적 회전 예측 (선택)

`python3 run_pi.py --direction ccw --adaptive-yaw --duration 8` 로 모터 없이 시작한다. 정지한 차에서는 실제 적용 PWM이 0이므로 계수가 갱신되지 않는다. 옵션을 생략하면 기존 단위 계수 1.0을 사용한다. 옵션 사용 시 좌회전 13/18, 우회전 1.0으로 매번 시작하고 두 방향을 별도로 관리한다. 계수는 차체 이동 예측에만 쓰며 출력 PWM에 직접 곱하지 않는다. 현재 여유 검사는 단위 계수와 학습 계수를 모두 평가한다.

어안·지면 보정값으로 분홍색 점선의 반복 밝기와 횡단보도의 평행한 흰 줄 배열을 검사한다. 같은 종류의 표식이 이전 영상과 위치·방향 모두에서 일치해야 같은 표식으로 이어 붙인다. 출발선과 신호 판정은 이 모듈의 입력이 아니다. 표식이 끊기거나 모호하면 누적 구간을 버린다. 4개 이상 연속 구간에서 한 방향 PWM 예측 누적 회전이 16° 이상이고 관측도 8° 이상이며 중간 프레임 각도들이 일관될 때만 관측각/PWM 원래 예측각 비율을 25% 반영한다. 한 번의 변화는 ±0.05 이내이고 다음 예측부터 쓴다. 좌우 PWM 변화가 없는 상태, 광택 단독, 불일치, 타이밍 이상은 학습 근거로 사용하지 않는다. CSV에서 next_left_yaw_gain, next_right_yaw_gain, gain_mark와 두 window 각도 열을 확인한다.

실차 저장 사진 186장을 정지 이후까지 독립 진단한 결과 분홍 점선 22장·횡단보도 29장, 좌회전 갱신 1회(0.7222→0.7151). 다음 코너의 독립 빨간 실선 측정 27.64°에 대해 예측 30.98°→30.67°. 내부 사거리 실차 검증은 아직 없다. A 점선으로 시작점을 정렬하고 정지 로직까지 적용한 재생에서는 9.982초에 여유 부족으로 중단되어 첫 학습 구간 끝까지 가지 않았다. 이상적 모의 외곽 폐루프는 양방향 모두 한 바퀴를 통과했다. 실기 Pi 연산 지연과 바닥 반사에 따른 오인식률은 미확인이다.
