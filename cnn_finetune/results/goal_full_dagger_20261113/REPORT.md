# 전체 학생 방문 상태 지도학습 비교

목표는 계속 진행 중이다. 이번 결과는 네 이동의 국소 개발 시험이며 완료 판정이나 실차 성능이 아니다. 최종 시험 시드 900000–999999는 사용하지 않았다.

## 고정한 비교

기존 추가 BC 60 epoch 모델에서 시작했다. 새 학습 시드 6101/6102, 차체 3종, 이동 4개, 기본·약한 복합·약한 복합+강한 조명을 완전 교차했다. 교사 72회, 학생 72회를 수집했으며 무이탈 성공은 각각 58회, 23회였다. 교사 성공 58개와 기존 깨끗한 교사 주행 60개를 합친 118개가 공통 풀이다. 기존 60개의 영상·행동 이력은 보존하고 수정 교사로 정답만 다시 계산했다.

두 학습군 모두 같은 초기 가중치, CNN 동결, GRU/출력부, seed17, 1200회 업데이트, 학습률 1e-4→1e-5를 썼다. 매번 이동별 한 에피소드씩 뽑은 공통 배치와 추가 배치에 각각 0.5를 곱했다. 공통 배치 순서는 해시가 같다. 추가 배치만 교사 풀 대 학생의 전체 방문 시퀀스로 달랐다. 정답은 회전 가중 SmoothL1이며 선호 loss는 없다. 최종 업데이트를 평가 전에 고정했다.

학생 데이터에는 실패도 보존했다. 캡처 시 차체 여유 ≥-3cm, 기준 경로 거리 ≤12cm, 방향차 ≤60도와 기존 전송 시 여유 마스크를 적용했다. 이 마스크는 정답의 안전성 보장이 아니다.

## 교사 정답 감사

학생 72개 주행을 저장된 명령으로 다시 실행하여 전체 물리 궤적이 원본과 정확히 같음을 확인했다. 사전 고정한 3/5/8/12/16초에서 교사에게 넘긴 359개 분기를 조사했다. 교사는 359개 모두 안정 출구에 도착했지만, 시작 시 차체가 도로 안이던 298개 중 이후 무이탈은 225개였다. 기본 92/103, 약한 복합 68/101, 약한 복합+강한 조명 65/94이다.

특히 5초 지점의 도로 안 상태 53개 중 25개만 이후 무이탈이었다. 경계 근처에서 교사의 경로 복귀 명령을 따라간다고 전체 차체의 침범이 방지되는 것은 아니다. 같은 에피소드의 분기들은 상관되어 있으므로 359개 독립 시험으로 간주하지 않는다. 이후 교란을 포함한 분기 평가는 오프라인 감사에만 사용하며 학생 입력에는 전달하지 않았다.

## 후속 진단

입력 계약과 구조를 유지하고 CNN 마지막 두 합성곱 층을 추가 학습하는 통제 비교를 별도 실험으로 고정했다. 데이터·배치·head 학습률·업데이트 수를 그대로 두고 교사군/학생 혼합군 각각 비교한다. 이 실험도 개발 시험이며 결과를 보고 완료 기준을 바꾸지 않는다. 교사의 경계 여유 부족은 별도 해결 과제다.

추가로 고정한 24개 공통/학생 배치에서 gradient를 비교했다. 초기 모델의 학생/교사 gradient norm 비율 중앙값은 2.14이고 10/24개가 서로 반대 방향이었다. 교사만 추가 학습한 모델에서는 3.61과 15/24였다. 50% loss 혼합이 실제 학습 영향 50%를 의미하지 않음을 보여주지만, 이는 raw gradient 진단이며 AdamW 업데이트나 폐루프 실패 원인에 대한 인과 증명이 아니다. `source_gradient_audit.json`에 배치별 수치를 보존했다.
