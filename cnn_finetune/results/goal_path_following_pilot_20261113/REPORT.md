# 영상 기반 부드러운 경로 추종 사전 검증

2026년 11월 13일. 신경망 학습 전에 알려진 부드러운 경로를 영상 기반 위치 추정과 피드백 제어로 따라갈 수 있는지 검사했다.

**판정: 기본 동작은 가능하지만 대규모 학습으로 확대하는 사전 기준에는 미달했다.** 영상 방식은 24/24회 올바른 출구에 안정적으로 도착했고 불필요한 정지는 없었지만, 전체 차체 무이탈은 19/24회였다. 대조군과 개입 실험을 통해 느린 차량의 응답 지연 보상이 구체적인 제어 병목임을 확인했다. 영상 위치 오차도 별도의 잔여 문제다.

**시험 구성**

취약 이동 north/E/left, north/W/right와 대조 이동 center/N/right, east/W/right를 골랐다. 차량은 기준·느린 응답·좌우 출력 비대칭 3종, 새 개발 시드는 22001/22002다. 4×3×2=24개 정상 조건을 각 방식에 동일 적용했다. 정답 위치와 이벤트 목록이 짝별로 동일함을 확인했다.

기존에 차체 여유와 곡률을 검토한 부드러운 경로를 고정했다. 알려진 지도·경로와 명목 출발 위치를 제공했으며, 실제 무작위 초기 자세를 영상 제어기에 주지 않았다. 이 시험은 경로 선택·표지판 인식·경로 예측 CNN·전체 미션의 검증이 아니다.

제어기는 곡률 피드포워드와 방향/횡오차 피드백을 사용한다. 모터 출력 계수 16.8cm/s/duty, 트랙 13cm, 회전 효율 0.6, 명목 구동 지연 0.05초와 응답 시정수 0.10초를 모든 차량에 동일 적용했다. 영상 방식은 기존 pinned v4의 영상-지도 정합 추정기를 사용했다. 실제 속도·차량 preset·정답 자세를 제어기에 전달하지 않았다. 움직임 예측은 전송 PWM과 명목 모터 모델에 의존하며, 독립적인 영상 속도 추정 신경망을 새로 만든 것은 아니다.

영상은 RealCam의 typical 조건이며 최대 30Hz, 제어 처리 지연 36ms, 영상 지도 추정은 3프레임마다 70ms 지연 후 공개한다. 실제 장치의 처리시간 측정이 아닌 시뮬레이션 시간 설정이다. 차체 침범은 전체 직사각형 윤곽과 도로 기하를 물리 샘플 시점마다 검사했다. 샘플 사이 연속 시간에 대한 수학적 안전 증명은 아니다.

실행 전 정상 확대 기준은 각 대조군과 영상 방식 모두 무이탈 ≥22/24, 안정 출구 24/24, 잘못된 출구·심한 이탈·불필요한 정지 0회로 고정했다. 미달하면 복합 교란 확대와 대규모 학습을 하지 않는 개발 게이트다. 원래 목표의 최종 합격 기준을 변경하지 않았다.

정답 상태 교사는 경로가 해당 조건에서 가능한지 확인하는 추가 진단 대조군이다. 후보 제어기와 같은 정보 제한을 가진 모델이 아니다. 다른 세 방식의 제어 수식과 경로는 동일하며 관측 경로만 다르다. 지연 정답 대조군은 같은 관측 주기·지연과 명목 명령 재생을 사용하지만, 영상 추정기의 적응·정합 로직 전체를 복제하지는 않는다.

| 이동 | 현재 정답 위치 | 지연 정답 위치 | 영상 추정 | 실제 특성을 아는 교사 |

고정 명목 제어의 4회 실패는 모두 느린 차량의 좁은 삼거리 회전이다. 최악 차체 침범은 현재 정답 위치 대조군 약 0.741cm, 지연 정답 위치 약 1.028cm, 영상 방식 약 1.070cm였다. 안정 출구 도착이 도중 무이탈을 뜻하지 않으므로 모두 실패로 유지한다.

영상 방식의 에피소드별 위치 오차 95백분위수 중앙값은 0.770cm다. 지연 정답 대조군은 0.129cm다. 주행 시간 중앙값은 각각 20.347초와 20.149초였다. 실제 A5b+v4와의 동일 조건 비교는 아니므로 기존 방식보다 빠르거나 부드럽다는 결론으로 사용하지 않는다.

**지연 보상 문제를 분리한 개입**

느린 차량의 같은 8개 정상 조건 전체를 대상으로, 정답 위치를 쓰면서 한 항목씩 바꾸었다. 별도 프로토콜을 먼저 저장했으며 이득·속도·경로를 탐색하지 않았다. 수정하지 않은 수식이 기존 저장 명령을 재생하는지 확인한 뒤 개입했다.

| 정답 위치를 사용하는 느린 차량 제어 | 무이탈 |
|---|---:|
| 기존 명목값 | 4/8 |
| 출력 계수만 실제 값으로 보정 | 4/8 |
| 예측 시간을 실제 지연+시정수에 맞춰 0.15→0.40초로 변경 | 8/8 |

이 실험에서는 **지연을 고려한 선행 제어가 네 실패를 없앴다.** 단순히 모터 출력 계수를 정확하게 넣는 것만으로는 해결되지 않았다. 느린 차량이 회전 명령에 늦게 반응하는 문제를 영상 CNN이나 새로운 loss가 자동으로 해결해 줄 것이라고 기대해서는 안 된다.

0.40초는 실제 시스템에서 추정한 값이 아니라 시뮬레이터 차량 설정을 아는 오프라인 진단값이다. 따라서 실제 차량에 그 값을 전달하는 방식으로 채택하지 않는다. 필요한 것은 별도 응답 보정 또는 불확실한 응답에 견디는 제어다.

같은 보상을 영상 추정과 결합하는 추가 진단도 수행했다. 같은 느린 차량 8회에서 영상 무이탈은 **4/8→7/8**, 성공 전환 3회·기존 성공 손실 0회였다. 8회 모두 안정 출구에 도착했고 불필요한 정지는 없었다. 실패 1회는 north/E/left, seed22001이며 최악 침범은 0.530cm였다. 따라서 지연 보상은 영상 폐루프에서도 실질적으로 기여했지만 영상 추정의 잔여 실패까지 없애지는 못했다.

이 추가 진단은 고정된 0.40초 한 값만 적용했고, 같은 영상·지도 추정기·명목 운동 모델·속도·제어 이득·allocator를 유지했다. 초기 상태와 이벤트 목록의 일치를 확인했다. 0.15초 설정에서 변경 수식의 기존 명령 재생 일치를 먼저 확인한 후 실험했으며, 새 결과를 별도 경로에 저장했다. 원래 24회 시험 결과나 확대 기준을 대체하지 않는다.

**영상 추정의 잔여 문제**

영상 방식에서 추가로 실패한 기준 차량 north/E/left, seed22001은 현재·지연 정답 위치 대조군에서는 모두 무이탈이었다. 영상 방식은 약 9.93초에 첫 침범이 발생했고 최악 침범은 약 0.158cm였다. 첫 침범 직전/시점의 추정 오차는 차량 기준 횡방향 약 -1.17cm, 진행 방향 약 -1.27cm, 방향 약 2.34도였다. 당시 추정기는 `observed` 상태였다.

정합 통과가 정확한 위치를 보증하지 않는다는 문제가 이 시험에서도 드러났다. 좁은 회전에서는 경로 자체의 차체 여유에 비해 추정 오차가 커질 수 있다. 실패 뒤의 큰 궤적 차이를 원인으로 오인하지 않도록 첫 침범 이전의 오차를 별도로 저장했다.

이 결론은 기존 영상-지도 추정기를 쓴 이번 구조에 해당한다. 영상에서 차량 기준 경로를 직접 예측하는 모든 구조가 불가능하다는 증거는 아니다.

**다음 개발 판단**

대규모 CNN 학습은 보류한다. 먼저 차량 응답의 지연 보상과 삼거리의 영상 위치 오차를 개선해야 한다. 새 시드에서 같은 작은 정상 시험을 통과한 다음 약한 밀림·출력 변화와 강한 조명 쌍으로 확대한다. 현재 정상 실패를 남겨 둔 채 더 큰 데이터 수집으로 넘어가지 않는다.

이번 결과는 새 경로/제어 분리 방향을 포기할 근거가 아니다. 알려진 경로로 모든 사례에서 출구까지 이어지는 주행이 가능했고, 제어 실패의 일부를 단일 물리 항목으로 설명·해소했다. 다만 대규모 학습 전에 충족해야 할 하위 시스템의 정확도와 적응 능력이 아직 부족하다.
