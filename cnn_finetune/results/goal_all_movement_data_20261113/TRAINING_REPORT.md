# 28개 이동 시연 수집과 첫 학습

## 데이터

28개 이동(회전20, 직진8), 학습 시드6801/6802, 차량 특성3종, normal/mild/mild_light를 조합한504개 에피소드를 모두 보존했다. 일반 조명과 강한 조명168쌍의 물리 궤적은 정확히 같았다. 실패를 삭제하거나 평가 분모에서 제외하지 않는다.

무이탈 안정 출구와 불필요한 정지 없음 조건을 만족한442개만 초기 행동 모방 학습에 사용했다: normal168/168, mild137/168, mild_light137/168. 깨끗한 시연 중 정지 때문에 추가 제외한 사례는0개다. north_E_left와 north_W_right는 각각 정상6개뿐이고, mild/mild_light 성공 시연은0개다. 두 이동의 교란/조명 학습 공백을 남겨 둔 기준 모델이며 이 공백이 해결됐다는 주장은 하지 않는다.

카메라 보정 파일, 배경 이미지 목록과 파일 해시, 시뮬레이터·교사 코드와 참조 경로를 고정했다. 학생 입력은 영상의 고정 CNN 특징, 이전 실제 PWM, 직진/좌/우 지시다. 시뮬레이터 정답은 교사와 채점에만 사용했다.

## 학습

RTX4060에서 초기화17로2,400업데이트를 완료했다. CNN은 고정했고, 특징 투영부·GRU64·PWM 출력부190,050개 매개변수를 학습했다. 전체 시연을 패딩해7개씩 묶고, 매4업데이트마다28개 이동을 모두 방문했다. 학습 순서 난수는221로 고정했다.

목적 함수는 에피소드별 정규화한 SmoothL1(beta0.05)이고, 좌우 PWM 차이가0.15보다 큰 프레임에3배 가중치를 주었다. 이번 단계는 새 교사·이동 범위에 대한 BC 기준 모델이다. 새로운 폐루프 outcome loss의 효과를 입증한 실험은 아니다. 패딩 길이가 손실과 실제 프레임 기울기를 바꾸지 않는 검사를 통과했다.

최종 업데이트2,400체크포인트를 미리 선택했다. 중간600/1200/1800체크포인트는 진단용이며 주행 결과로 갈아 끼우지 않았다. 초기·최종 가중치 해시는 다르다. 캐시한 CNN 특징을 사용하므로 최적화 루프 자체는 약16.6초였고, 영상 렌더링·특징 추출과 저장을 포함한 시연 수집이 약36.5분으로 훨씬 길었다.

## 시연 적합도 진단

| 조건 | 기존 네 이동 모델의 PWM MAE | 새28개 이동 모델의 PWM MAE |
|---|---:|---:|
| normal | 0.06337 | 0.01489 |
| mild | 0.06280 | 0.01722 |
| mild_light | 0.06456 | 0.01756 |

같은442개 학습 시연의 영상과 교사가 보낸 이전 PWM을 입력한 값이다. 에피소드별 MAE를 같은 비중으로 평균했다. 독립 검증 오차나 학생이 실제로 만드는 상태 분포의 오차가 아니므로, 실제 주행 성공률로 바꾸어 해석하지 않는다.

별도6901시드의28개 이동 정상 폐루프 비교는 goal_all_movement_eval_20261113에 기록한다. 강한 조명 포함504회 전체 평가, 다른 두 초기화의 재현성, 전체 경로·harsh·독립 최종 시험은 아직 남아 있다. 배포 모델과 합격 기준은 바꾸지 않았다.
