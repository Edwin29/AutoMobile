# 전체 경로 방향 명령 연결 준비

DirectionResolver는 기존 JunctionPolicy 규칙을 사용하고 조향 PWM을 생성하지 않는다. 호출자가 영상에서 추정한 위치·불확실성을 공급해야 하며, 시뮬레이터 실제 위치를 연결하면 입력 계약 위반이다. 신경망에 전달할 값은 straight/left/right 지시뿐이다.

32개 정적 경로를 합성 위치 추정 입력으로 재생했다. 경로별 도착·출구 방향, 명령 중복 소비 방지, 잘못된 출구에서 조기 완료 방지, 불확실하거나 비정상인 관측의 상태 전이 금지, 중앙 우회전 시 큐 유지와 불가능한 T자 명령 처리 검사를 통과했다. 이는 인식 정확도나 실제 주행 성공의 증거가 아니다.

아직 필요한 연결:

- 실제 영상 지도 추정기의 관측 지연과 실제로 보낸 signed PWM 반영을 검증해야 한다. 이전 제어기의 제안 출력을 지도에 보내면 안 된다.
- 기존 34cm 진입·40cm 출구·55cm 재진입 제한을 사용한 상태 처리다. 국소 시연은 방향 지시를 전체 에피소드 동안 유지하므로, 실제 연속 경로의 지시 전환과 GRU 상태 유지에 대한 데이터·검증이 따로 필요하다.
- 바깥 코너와 교차로 사이 연결 구간, 명령 만료, 정지/재개를 포함하는 전체 실행기를 아직 통합하지 않았다.
- 최초 위치 힌트는 알려진 출발 구역 중심이어야 한다. 무작위 실제 초기 위치나 경로 진행 정답을 넘기지 않는다.
- 마지막 출발 구역 복귀는 선언한 전체 통과 순서와 함께 채점해야 한다. 기존 bench의 300cm 이상 이동 조건만으로 완료 처리하면 안 된다.

기존 제어기, 시연 수집, 학습 입력 및 완료 기준은 변경하지 않았다.
