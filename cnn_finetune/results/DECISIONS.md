# 결정 기록

- 2026-11-11: main 3d51ada의 자율 진행 규칙을 적용한다. 교사 수정 8회, 데이터 생성 3회, 학습 4회 예산을 구분해 기록한다. 이전 실패 즉시 중단 규칙은 대체됐다.
- 기준선은 기본 4차량 × 양방향, realcam, seed 41, own(36ms), 200초로 측정한다. 이전 교사와 동일 배치/채점으로 비교하기 위해서다.
- 기존 bench.run에는 --cnn-mixer 옵션이 없으므로 cnn_finetune/baseline.py에서 기존 HybridCNN.CNN_MIXER 설정을 v4로 지정해 동일 run 함수를 호출한다. 기존 코드 파일의 동작은 변경하지 않는다.
- 자원 보호를 위해 우선 단일 시험 프로세스를 사용한다. D: 여유 약 1.29TB. 대용량 로그는 저장소 밖에 둔다.
- 기준선 첫 완료 조건 field_estimate/cw는 완주, 최소 여유 +1.8373cm다. 기존 교사는 같은 조건 -1.6362cm이며 바깥 코너 침범이므로 교사 제어 문제로 판단한다. 나머지 기준선을 계속 측정하면서 수정 1(0.19초 지연 예측)을 동일 물리/채점의 렌더 없는 진단에서 먼저 비교한다.
- 수정 1에서 기본 차량 바깥 침범이 지속된다(cw -1.36cm, ccw -1.86cm). 수정 2는 순서대로 경로 곡률 feedforward와 횡/방향 오차 피드백을 적용한다. 각 진단은 카메라를 생략하며 단계 합격 자료로 사용하지 않는다.
- 수정 2도 기본 차량에서 침범이 남는다. 수정 3은 |k|>0.03에서 요청 평균 듀티를 0.36으로 낮춘다. 할당기가 듀티를 다시 올리는 구간에서는 실제 감속 효과가 제한될 수 있으므로 실제 궤적으로 판단한다.
- 수정 4는 지연 보상+순수 추종의 앞보기를 12cm로 줄여 코너 추종을 비교한다. 수정 5는 25cm로 늘려 조기 조향 효과를 비교한다. 이전 feedforward 항과 중복해 앞보기 변경 효과가 숨지 않도록 두 후보는 순수 추종 기준이다.
- 수정 6은 v4/실제 차량 회전 효율 비율을 교사 목표 곡률에만 적용한다. 정답 역산의 v4 상수는 유지한다. 기본 차량별 시뮬레이터 파라미터는 교사 진단에만 사용한다. 수정 7/8은 남은 바깥 코너 오차에 대응해 |k|>0.02 구간에 각각 0.003/0.006의 회전 방향 곡률 보정을 추가한다. 상한 0.055는 유지한다.
