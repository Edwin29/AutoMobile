# CNN 후반부 학습과 데이터 출처의 통제 비교

목표는 미완료이며 계속 활성 상태다. 네 이동 국소 개발 시험에서 학습 범위와 데이터 출처를 비교했다. 이번 네 모델은 교체 후보로 채택하지 않는다. 학생 방문 상태의 정답 오차를 낮추면서 정상 진입 오차가 커지는 현상이 관측됐으며, 마지막 두 CNN 층을 학습하는 것만으로 해결되지 않았다.

## 비교 조건

모든 모델은 추가 BC 60 epoch 체크포인트에서 시작했다. 118개 교사 시퀀스와 72개 학생 방문 시퀀스, 공통 배치와 추가 배치 각 4개, 1200회 업데이트, head 학습률 1e-4→1e-5, seed17, 마스크와 회전 가중 SmoothL1을 동일하게 유지했다. 공통 배치 순서가 이전 동결 실험과 같은지 해시로 확인했다. CNN 후반부의 학습률은 head의 0.1배이며 앞 세 합성곱 층은 고정했다.

학습 파라미터는 GRU/출력부 등 190,050개에서 CNN 마지막 두 층을 포함한 254,690개가 됐다. 구조와 입력은 영상 이력·이전 전송 PWM·방향 지시로 동일하다. 각 모델의 최종 1200회 체크포인트를 주행 평가 전에 고정했다. 초기화 한 번의 비교이며 임의 재시도나 결과 기반 체크포인트 선택은 하지 않았다.

## 다음 개발 우선순위

1. 현재 50% 혼합 방식을 그대로 확대하지 않는다. 정상 주행 보존 여부를 명시적으로 측정하면서 복구 항의 영향과 교사/학생 분포 간 간섭을 제한하는 loss를 통제 비교한다. 가중치만 감소시켜 성공했다고 판단하지 않는다.
2. 경계 근처 정답의 품질을 먼저 높인다. 교사가 중심선으로 돌아오는 것뿐 아니라 차체 앞뒤 전체의 경계 여유를 유지하는지 확인한다. 시뮬레이터 정보는 오프라인 교사와 채점에만 사용한다.
3. 이 네 이동의 개발 개선 후 필수 28개 이동, 연결 미션, 세 학습 초기화, 미사용 최종 시드로 확대한다. harsh의 사전 정의와 복구 가능성 검증은 여전히 미완료다.
4. 완료 기준·입력 계약·근본적 구조 전환이 필요한 경우 변경 전에 사용자에게 보고한다. 현재 목표를 낮추거나 실패 조건을 제거하지 않았다.

## 검사와 보존

190개 시퀀스, 102,741프레임에서 앞 세 CNN 층을 캐시했다. 시퀀스별 최대 16개 프레임의 기존 특징과 재계산 특징 차이는 최대 8.35e-7이었다. 실제 영상으로 gradient·고정층 불변·후반층 변경·전체 모델 저장/재로딩 출력 일치 검사를 통과했다. 학습 후 두 후보의 앞 세 층이 정확히 유지되고 후반 두 층이 변경됐는지 다시 확인했다. 평가기는 변경된 CNN 전체와 GRU/출력부를 함께 로딩했다.

초기 encoder와 초기 head, 학습 소스의 해시를 원래 프로토콜과 대조했다. 검사 코드에서 GRU backward를 위한 train 모드 누락을 학습 전에 수정했고, 이전 프로토콜과 소스도 보존했다. 학습이나 평가 알고리즘은 그 수정으로 바뀌지 않았다.
