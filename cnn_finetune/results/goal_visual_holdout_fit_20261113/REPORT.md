# 낮은 시연 오차와 나쁜 폐루프 성적의 분리 진단

새28개 이동 모델은 정상 폐루프 시험에서27/84무이탈,21회 심한 이탈로 채택을 거부했다. 이전 네 이동 모델은23/84무이탈,심한 이탈0회였다. 이 문서는 그 원인을 구분하기 위한 개발 진단이며, 최종 시험이나 개선된 모델의 증명이 아니다.

## 새 영상에 대한 적합도

같은6901교사 궤적84개를 영상으로 다시 생성했다. 모든 물리 궤적은 앞선 비영상 교사 시험과 정확히 같았다. 영상·이전 실제 교사 PWM·방향 지시를 두 모델에 동일하게 넣고 각 에피소드 시작에서 GRU를 초기화했다. 이 자료는 학습용으로 사용하지 않는다.

| 정상 조건의 에피소드 평균 PWM MAE | 기존 모델 | 새 모델 |
|---|---:|---:|
| 학습 시연168개 | 0.06337 | 0.01489 |
| 새 시드의 교사 시연84개 | 0.06171 | 0.02340 |
| 새 시드에서 교사가 무이탈한70개만 | 0.06799 | 0.02389 |
| 새 시드의 첫3초 | 0.07392 | 0.04513 |

새 모델은 새 영상에서도 기존 모델보다 오차가 작지만, 실제 학생 폐루프에서는 심한 이탈이 늘었다. 새 영상 분포의 오차 증가는 존재한다. 다만 교사 궤적 위의 오차만으로는 학생이 스스로 만드는 상태 분포와 피드백 안정성을 판단할 수 없다.

## 손실이 허용하는 지름길

학습 시연에서 영상 없이 이전 실제 PWM의7프레임 이동평균만 계산하면 MAE는 normal0.01481,mild0.01758이다. 새 신경망의0.01489,0.01722와 비슷하다. 실제 학습 목적 함수인 회전 가중 SmoothL1도 영상 없는7프레임 평균이 normal0.00580,mild0.00841이고, 새 모델은0.00439,0.00745다. 신경망은 더 낮지만, 단순 행동 이력으로도 낮은 목적 함수 값에 접근한다.

이 계산은 교사가 실제로 보낸 PWM을 계속 제공하는 조건이다. 이 정책을 실제로 실행해 성공했다는 뜻이 아니다. 이전 PWM이0인 출발 상태에서 이 이동평균 정책만 반복하면 출력도0으로 유지된다는 점만 보아도 낮은 시연 오차와 운전 능력의 차이가 드러난다. 이 마지막 문장은 수식상 관찰이며 실제 주행 실행 결과가 아니다.

행동 이력으로 정답을 쉽게 예측하는 문제는 모방학습의 copycat/causal-confusion 연구와 관련된다. 이 프로젝트에서의 원인 확정이나 논문 방법의 효과를 입증한 것은 아니다. [NeurIPS2020 원문](https://proceedings.neurips.cc/paper_files/paper/2020/hash/1b113258af3968aaf3969ca67e744ff8-Abstract.html), [ICML2021 원문](https://proceedings.mlr.press/v139/wen21d/wen21d.pdf).

## 실제 신경망의 입력 민감도

새 시드84개 교사 시연을 그대로 재생하되 입력만 바꿨다. 영상 특징을 첫 프레임으로 고정하면 새 모델 MAE는0.02340→0.06965,이전 PWM을0으로 바꾸면0.04127이 됐다. 따라서 새 모델이 영상을 무시한다고 단정할 수 없다. 두 입력에 모두 민감하다. 기존 모델의 이전 PWM 제거에 따른 예측 변화 MAE는0.01278,새 모델은0.03504였다.

이 개입은 실제 영상과 명령 이력이 서로 맞지 않는 비현실적 입력을 만들 수 있다. 정책의 예측 민감도를 측정한 것이며, 실제 주행 실패의 단일 원인이나 보상에 대한 인과 효과를 증명하지 않는다. 이 결과만으로 이전 PWM 입력을 제거하지 않는다.

## 데이터 범위의 확인된 공백

학습 초기 상태를 결정한 두 시드의 횡방향 추출값은6801약-0.00035cm,6802+0.47061cm였다.6901은-0.96768cm였다. 첫3초의 새 모델 MAE도 학습0.01949에서 새 시드0.04513으로 증가했다. 이는 반대쪽 초기 오차 범위가 학습에서 부족했다는 명확한 표본 설계 문제다. 다만 전체 실패의 유일한 원인으로 확정하지 않는다.

다음 단계는 결과를 보지 않고 초기 횡방향·각도 영역8개를 먼저 정한 뒤 각 영역에 맞는 시드를 고정하는 것이다. 기존 교사를28개 이동×3개 차량×8개 시드,672회 정상 물리 조건에서 사전 점검한다. 초기 자세 투영과 실패는 모두 보존한다. 평가의 초기 상태 분포, 성공 기준, 학생 입력은 바꾸지 않는다. 이 점검은 새 학습 자료의 양쪽 오차 범위가 빠지지 않게 하려는 절차이며 최종 목표 합격 판정이 아니다.
