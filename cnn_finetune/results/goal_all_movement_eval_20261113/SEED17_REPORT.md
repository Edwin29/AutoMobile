# 28개 이동 모델 첫 폐루프 비교: 채택하지 않음

시드6901, 정상 조건,28개 이동×3개 차량의84회를 동일 초기 자세로 비교했다. 새 모델은504개 중442개 무이탈·무정지 시연으로 학습한2,400업데이트 고정 체크포인트다.

| 항목 | 기존 네 이동 GRU | 새28개 이동 GRU |
|---|---:|---:|
| 전체 무이탈 성공 | 23/84 | 27/84 |
| 안정 출구만 | 50/84 | 42/84 |
| 잘못된 출구 | 25 | 18 |
| 심한 이탈 | 0 | 21 |
| 불필요한 정지 사례 | 0 | 0 |
| 기존 네 이동 무이탈 성공 | 5/12 | 6/12 |

대응 사례에서12개 성공을 새로 얻었지만8개 기존 성공을 잃었다. 순성공4회 증가보다 심한 이탈21회 발생을 우선하여 채택하지 않는다. 기존 모델도 목표 합격 모델은 아니다.

시연 오차는 크게 줄었지만 주행 안전성은 악화됐다. 이전에 없던 이동을 추가했다는 사실만으로 안전한 일반화가 확보되지 않았다. 다른 초기화 반복이나 강한 교란 시험 확장 전에 새 영상 조건의 모방 오차와 학생 자신의 상태·PWM 피드백으로 발생하는 분포 차이를 구분한다.6901의 교사 궤적에 대한 영상/오차 진단을 별도 실행 중이며, 그 자료는 학습에 사용하지 않는다.

이번 것은 BC 데이터 범위 확장 기준 모델의 실패다. 새로운 outcome loss, CNN 전체 미세조정, DAgger 복구 재학습의 실패로 확대 해석하지 않는다. 독립 최종 시드는 사용하지 않았고 합격 기준, 학생 입력, 배포 모델은 유지했다.
