# 복합 교란 복구와 연속 교차로 회전 학습 계획

2026-11-12 작성. 기존 세션과 현재 코드에 근거한 다음 실험 계획이다. 새 본학습은 아직 시작하지 않았다.

목표는 약한 복합 교란에서도 복구하는 주행과, 가능한 교차로에서 불필요한 정지 없이 이어지는 회전이다. 평가 기준과 실행 조건을 먼저 고정하고, 연속 경로의 실행 가능성, 학습 목표, 시간 기억, 가중치 자동 조정의 효과를 단계별로 구분한다.

## 기존 세션에서 이어받을 결정

직접 검토한 대화는 **CNN 파인튜닝 3단계 진행**의 첫 작업부터 최종 DAgger 결과와 후속 오차 해석까지다. 대화 식별자는 `01a1ca3c-8763-70c3-a1f5-7f3e38ce0db8`이다. **자율주행 라인트레이싱 보정** 대화도 참고했다. 노트북의 **라인트레이서 만들기** 원본 대화는 현재 조회 가능한 목록에서 찾지 못했으므로, 해당 교차로 작업은 이관된 문서와 현재 소스를 근거로 삼는다.

## 0 기준선과 평가 계약

외곽 기준선은 A5b + v4와 direct_v2를 고정한다. 교차로/미션은 현재 hyb2j/hyb2m의 제자리·분할 회전 동작을 기준선으로 기록한다. 외곽에서 좋은 모델을 교차로에서도 검증됐다고 간주하지 않는다. 코드 커밋과 미커밋 실험 코드 해시, ONNX/체크포인트 해시, 카메라 및 차체 설정을 함께 남긴다.

기존 240회와 seed 41/42, 601/607/613 및 기존 학습·검증·시험 시드는 이미 관찰한 자료다. 기존 시험 자료를 새 학습 데이터로 옮기지 않으며, 앞으로의 개선 주장에는 새 최종 시험 시드를 사용한다. 이번 39개 선호 쌍은 세 진단 상태에서 만들어졌으므로 독립 표본 39개로 세지 않는다.

평가 우선순위 초안은 심한 이탈·잘못된 출구·임무 실패를 줄이고, 이탈 없는 성공을 늘리며, 그 조건에서 복구와 부드러움을 개선하는 것이다. 매끄럽게 틀린 출구로 나가거나 정지 명령을 무시하는 행동은 개선으로 인정하지 않는다.

안정 복귀 기준은 차체 경계 여유, 목표 경로/출구의 횡오차, 방향 오차를 함께 본다. 초기 개발 기준 후보는 여유 0cm 이상, 횡오차 1cm 이내, 방향 오차 5도 이내를 1초 유지하는 것이다. 경로 기하에 맞게 정의를 확인한 뒤 학습 전에 고정한다. 옛 heading-only 지표는 비교용으로 별도 보존한다. 미복귀를 회복시간 평균/중앙값에서 조용히 제외하지 않고, 미복귀율과 제한 시간 내 복귀율, 복귀시간 상위 구간, 재이탈을 함께 기록한다.

교차로 성공은 올바른 출구 도달 후 출구 도로에 안정적으로 정렬하는 것까지 포함한다. 부드러움은 고정 시간 척도에서 차체 가속·회전속도 변화와 불필요한 정지 횟수/시간으로 평가한다. 노이즈를 증폭하는 미분과 임의 필터 선택을 피하도록 계산 방법도 고정한다. 의무 STOP/신호 정지는 불필요한 정지 비용에서 제외한다.

새 비용에는 잘못된 출구와 출구 정렬, 차체 움직임의 연속성이 필요하다. 현재 `trajectory_loss.py`의 외곽 복구 비용을 그대로 교차로 점수로 쓰지 않는다. 특히 15초 종료 때 경계 안에 있다는 사실만으로 안정 복귀를 판정하지 않는다.

## 1 실행 루프와 행동 표현

새 수집기는 bench의 촬영 시각, 처리 지연, 명령 큐, 차체 지연, 카메라 노출 이력, 지도 가드 상태를 유지한다. 학생과 교사가 낸 제안 명령, 제한 뒤 실제 전송 명령, 시뮬레이터의 실제 움직임을 구분해 기록한다. 실제 전송 명령은 엔코더로 측정한 속도가 아니다.

먼저 같은 정책을 수집 모드와 평가 모드에서 실행해 프레임·명령·자세·난수 흐름의 재현을 검사한다. 할당기의 디더와 시간 기억은 실제 제어 단계마다 한 번 갱신하고, 교사 평가나 후보 탐색 때문에 배포 정책 상태가 추가로 변하지 않게 한다.

외곽 loss 비교에는 기존 direct 출력 계약을 유지한다. 교차로 새 모델에는 별도 버전의 signed 좌우 구동 명령을 우선 후보로 둔다. 전진·안쪽 바퀴 정지·역회전·낮은 속도 회전·정지/재개를 표현할 수 있는지 확인한다. 기존 전진용 곡률 변환에서 부호를 잃거나, 역회전을 지도 예측에 정지로 전달하는 문제가 없어야 한다. 기존 `HybridJunction._apply_now`의 부호 있는 운동 전달을 참고한다.

출력 하한·최대값·반전 및 변화율 처리는 실제 구동 가능 범위에 맞추되, 일반적인 저역통과 필터를 넣어 지연을 더 키우지 않는다. 디더링을 쓰는 경우 PWM 자체의 고주파 변화와 실제 차체의 부드러움을 구분한다.

## 2 연속 교차로 경로와 교사 후보

기존 `bench/junction.py`의 지도·차체 윤곽·진입/출구 판정을 재사용한다. 모든 삼거리의 각 진입 방향과 가능한 출구를 목록화하고, 가운데 사거리는 현재 미션 규칙인 우회전을 우선 평가한다. 실험적으로 가능한 다른 출구와 과제에서 허용된 이동은 따로 표시한다.

기존 원호와 제자리/분할 회전을 후보로 유지하면서, 곡률과 속도가 변하는 경로 및 연속 좌우 명령을 추가 탐색한다. 학습 전에는 정답 상태를 쓰는 시뮬레이션 탐색기가 실행 가능성을 검사할 수 있다. 해당 정답 상태는 실차 학생 입력으로 넘기지 않는다.

정적인 선 위 여유만 확인하지 않고 실제 차량의 출력 문턱·포화·지연·회전 효율·역회전 밀림을 넣어 전체 차체가 통과하는지 검사한다. 여러 차체와 약한 복합 교란에서 검증된 후보를 교사/선호 데이터로 사용한다. 후보가 경계를 밟았다는 이유로 무조건 버리면 복구 학습이 사라지므로 실패와 복구 과정도 별도 보존한다.

각 이동을 ‘연속 경로 확인’, ‘짧은 정지/반대 바퀴 구동을 포함하면 확인’, ‘현재 탐색에서 미해결’로 기록한다. 미해결을 물리적 불가능으로 단정하지 않는다. 원호가 가능한 동쪽 진입만으로 결과를 대표시키지 않고, 폭이 좁은 남·북 삼거리 합류와 중앙 사거리를 포함한다.

이 단계의 결과가 학습할 목표의 품질을 결정한다. 기존 레거시 교사만 그대로 복제하면 끊기는 동작도 그대로 정답이 되므로, 최소한 일부 교차로에서 더 나은 연속 후보가 실제로 통과하는 것을 먼저 확보한다.

## 3 시퀀스 데이터와 분기 주행

새 데이터에는 정상 외곽, 코너, 교차로 진입·회전·출구 정렬, 교란 후 복구와 실패를 모두 포함한다. 기존의 교차로 35cm 제외 규칙은 새 수집기에 적용하지 않는다. 교차로마다 방향 지시와 해당 지시가 유효한 구간을 함께 저장한다.

필수 기록은 원본/전처리 영상, 촬영·명령 적용 시각, 제안/적용 PWM, 이전 명령, 방향 지시, 에피소드/분기 ID, 교란 일정, 평가용 실제 자세·속도·차체 여유·출구다. 지도 추정치를 입력으로 쓸 때는 추정치와 신뢰도만 넣고 정답 자세와 분리한다. 학생 입력 목록을 명시해 정답 상태 누출을 검사한다.

시간 모델에는 프레임 순서가 유지된 짧은 연속 구간과 초기 기억을 만드는 준비 구간이 필요하다. 기존 NPZ의 무작위 프레임을 나열해 시퀀스로 간주하지 않는다. 데이터에 제외 구간이 있으면 연속성이 끊긴 것으로 처리한다. 새 에피소드에서는 기억을 초기화하고, 같은 상태에서 분기할 때는 그 이전 영상/명령 이력과 재구성된 기억도 공유한다.

좌우 반전을 사용한다면 전체 시퀀스, 좌/우 지시, 좌우 명령과 부호를 함께 바꾼다. 시간적으로 독립적인 밝기 증강이 가짜 움직임을 만들지 않게 한다. 차체와 지도의 좌우 비대칭을 무시한 반전은 별도 검증 없이는 적용하지 않는다.

환경은 다음 묶음으로 층화한다.

- 기본 환경과 차체 특성 차이.
- 밀림, 출력 증감, 조명을 따로 적용한 조건.
- 약한 밀림·출력 증감·차체 변동의 복합 조건.
- 약한 기계적 복합 교란에 강한 조명을 더한 조건.
- harsh 복합과 관측 상실 조건.

강한 조명을 넣은 묶음을 모든 요소가 약한 교란이라고 부르지 않는다. 외곽/교차로/합류 위치, 좌·우 방향, 출력 증가·감소를 균형 있게 포함한다. 외부 교란의 크기·빈도는 아직 실측 분포가 아니므로 합성 가정과 실제 기록을 구분한다.

같은 시작 상태의 모든 분기와 근접 프레임은 같은 데이터 분할에 둔다. 새 학습/개발/시험 환경 시드를 사전에 기록하고, 최종 시험은 모델과 가중치를 선택하는 데 사용하지 않는다. 실패 주변 상태만 수집하지 않도록 정상 주행 재생 자료도 유지한다.

## 4 고정 가중치 학습 비교

첫 소규모 학습은 기존 direct 출력과 외곽 과제에서 기존 모방 loss 대 결과 기반 loss를 비교한다. 동일한 초기 체크포인트와 동일한 원천 주행 자료를 사용한다. 모방 비교군에는 수집 상태의 교사 라벨, 결과 비교군에는 같은 자료에서 만든 분기 선호를 제공한다. 학습 표적이 다른 점과 업데이트/데이터 소비량을 기록한다.

새 교차로 모델의 최소 비교는 다음 네 가지다. 초기에는 같은 즉시 signed 출력 헤드를 사용해 미래 시퀀스 출력 효과가 섞이지 않게 한다.

| 모델 | 시간 입력 | 학습 목표 |
|---|---|---|
| C0 | 단일 영상 CNN + 방향 지시 | 모방 loss |
| C1 | 단일 영상 CNN + 방향 지시 | 결과 기반 loss |
| T0 | CNN + 작은 GRU + 방향 지시 + 적용 명령 이력 | 모방 loss |
| T1 | CNN + 작은 GRU + 방향 지시 + 적용 명령 이력 | 결과 기반 loss |

CNN 특징 추출부는 기존 모델에서 재사용한다. GRU 64~128은 초기 후보이며 먼저 한 크기를 고정해 비교한다. 출력 계약이 바뀌는 헤드는 새로 초기화하고, 재사용한 층과 동결/해제 시점을 명시한다. 방향 명령은 진입 전에 주고 출구를 벗어날 때까지 유지한다.

각 비교는 동일한 개발 시나리오와 가급적 3개 학습 초기화 시드로 반복한다. 모델 용량과 입력 정보가 다른 C/T 비교는 ‘시간 기억만의 순수 효과’라고 과장하지 않는다. 필요하면 같은 용량의 단일 프레임 비교군을 추가한다. 우선 실행 시간과 메모리를 측정하는 작은 수집/학습으로 규모를 산정한 뒤 확대한다.

현재 선호 loss는 고정 Gaussian 행동 점수의 평균 로그 비율을 쓰는 시제품이다. 좋은 분기의 점수 증가 없이 나쁜 분기만 낮추는 현상, 기준 정책에서의 과도한 변화, 행동 범위 포화, 교사 후보에만 의존하는 현상을 검사한다. 실패하면 선호 loss를 유지하는 것을 목표로 삼지 않고, 좋은 행동에 대한 회귀 보조항이나 결과 비용 기반 대안을 같은 개발 조건에서 비교한다.

새 모델이 스스로 만든 상태를 수집해 분기 자료를 갱신한다. 한 번 만든 direct_v2의 미래 결과 라벨만으로 여러 반복을 진행하지 않는다. 안정 복귀와 교차로 정상 출구 지표가 좋아질 때 다음 단계로 넘어간다. 훈련 loss 감소만으로 완료하지 않는다.

## 5 가중치 자동 조정

주행 평가 가중치와 학습 loss 혼합 가중치를 구분한다. 정책과 평가 가중치가 같은 점수를 동시에 낮추도록 두지 않는다. 실패/잘못된 출구/정지 명령 준수에 대한 고정 평가 기준을 유지한다.

첫 자동 조정 대상은 경계 여유·복구·정상 진행·차체 부드러움의 상대 비중과 기준 정책 유지 강도다. 양수 범위와 필요 하한을 정하고, 별도 개발 시드의 실제 주행 결과로 선택한다. 가중치를 0으로 보내거나 어려운 조건을 무시해서 점수가 좋아지는지 검사한다.

작은 가중치 벡터의 외부 탐색으로 시작한다. 각 후보로 정책을 짧게 학습해 폐루프 개발 성능을 비교하고 유망한 후보만 확대한다. 후보마다 비교 가능한 초기화와 업데이트 예산을 사용한다. 최종 후보는 독립 학습 초기화로 다시 확인한다. 고정 가중치 비교군에도 같은 총 계산 예산을 부여해 단순한 추가 탐색량의 효과를 구분한다.

개발 성능이 좋아지지 않으면 자동 조정 모듈을 추가하지 않는다. 상황별 가중치를 내는 MLP는 데이터가 충분하고 전체 가중치 조정의 이점이 확인된 뒤의 후보로 남긴다.

## 6 미래 명령과 결과 예측기

시간 입력과 결과 기반 학습의 효과를 확인한 뒤, 즉시 명령 대신 약 1초의 명령 시퀀스를 내는 헤드를 비교한다. 실제 적용은 첫 명령만 하고 매 영상에서 다시 예측한다. 출력 길이·제어 간격·학습 시퀀스의 의미를 맞추고, 길게 예측했기 때문에 효과가 있는지 같은 모델의 즉시 출력과 비교한다.

실제 분기 실행 비용이 병목이면 학습 전용 결과 예측기를 추가한다. 실패 위험, 경계 침범, 진행/복구 비용 등을 실제 rollout으로 지도 학습한다. 정답 상태를 쓰는 학습용 예측기와 실차에서 관측만 쓰는 정책의 입력을 구분한다. 예측기를 점수판으로 사용하는 동안에도 실제 bench 평가를 유지한다.

이 두 확장은 첫 본학습의 필수 조건이 아니다. 원래 문제를 해결하는 데 기여하지 않으면 구조를 늘리지 않는다.

## 7 전체 미션과 최종 평가

주행 모델에는 기존 `junction_policy`가 결정한 방향을 전달한다. 방향 큐, 중앙 사거리 우회전, 불가능한 명령의 기본값, STOP/재개 인터럽트는 기존 임무 계약으로 유지한다. 방향 지시가 없을 때마다 신경망이 출구를 새로 고르게 만들지 않는다.

구간별 좋은 결과 다음에는 외곽에서 삼거리로 진입하고 내부 도로와 중앙 교차로를 지나 다시 합류하는 전체 주행을 시험한다. 좌·우 방향과 시작 위치, 명령 지연, 회전 중 정지/재개, 기억 초기화·명령 소비 시점을 검사한다. 정지가 요구된 구간을 부드러움 비용 때문에 건너뛰지 않는지 확인한다.

이전 분할 회전은 새 모델과 비교할 기준선으로 남긴다. 새 모델 대신 기존 방식이 개입한 횟수와 주행 비율을 따로 기록해, 기존 제어기가 성공시킨 주행을 모두 CNN의 성과로 계산하지 않는다.

최종 보고는 모델별 전체 성적뿐 아니라 약한 복합·강한 조명 조합·harsh·교차로 종류별 성적을 보여준다. 동일 환경 시드의 쌍별 변화와 학습 초기화 변동을 함께 보고, 같은 에피소드의 프레임들을 독립 표본으로 계산하지 않는다. 최종 시험 결과를 보고 다시 모델을 고르면 해당 시험은 개발 자료가 된 것으로 표시하고 새 시험을 확보한다.

ONNX 변환 후 PyTorch와 실제 실행기의 출력·시간 기억 전달을 비교한다. 새 모델의 지연을 기존 36ms로 자동 가정하지 않고 지연 민감도도 시험한다. Pi 실측과 실차 확인은 실제 장비를 사용할 수 있을 때의 후속 단계다. 이번 계획 작성에서는 Pi 접속, 모터 동작, 모델 교체, 커밋/푸시, 새 학습을 수행하지 않았다.

## 첫 실행 묶음

다음 실제 작업은 단계 0~2로 묶는다. 평가 기준과 실행 조건을 고정하고, 현재 교차로 기준선을 재현한 뒤 남·북 삼거리 합류와 중앙 사거리에서 연속 후보를 탐색한다. 결과물은 평가 명세, 재현 검사, 이동별 경로/영상 및 실패 사유다.

이 자료로 교차로 학습의 목표가 준비되면 단계 3~4의 수집과 실제 학습을 진행한다. 후보가 발견되지 않은 이동은 별도 과제로 남기고, 연속 경로가 확보된 이동의 학습을 계속할 수 있다. 대규모 데이터 수집이나 새 신경망 학습으로 실행 불가능한 목표를 해결하려고 하지는 않는다.

## 2026-11-13 실행 기록

사용자 요청에 따라 단계 0~2를 실행했다. [실행 보고서](results/junction_stages02_20261113/REPORT.md)에 평가 계약, 수집/평가 재현 검사, signed 출력 검사, 36이동의 경로·비교 영상 및 실패 사례를 보존했다. 1296회 동역학 평가에서 안정 출구는 fixed 432/432, mild 복합 432/432, harsh 복합 379/432였고, 무이탈 안정 출구는 각각 364/432, 273/432, 21/432였다. 초기 경계 침범 배치도 분모에 포함했다.

기본 차체·중앙 정렬 시작에서는 36개 기하학적 이동 모두 연속 후보를 확인했다. 실제 미션 허용 이동은 28개다. 후보는 정답 자세를 쓰는 오프라인 교사이며 영상 CNN의 검증 결과가 아니다. 기본 조건의 후보 24개 회전은 일부 구간 반대 바퀴 구동을 사용한다. 모든 회전에 역회전이 필수라는 증명은 아니다.

방향을 근본적으로 바꿀 결정은 발견되지 않았다. 다만 약한 복합 교란에서도 경계 침범이 남아 있으므로 깨끗한 목표와 복구/실패 분기를 구분해야 한다. 단계 3 데이터 구축과 단계 4 새 신경망 학습은 시작하지 않았다. 최종 시험 시드는 미사용이다.

### 코너링 목표 경로 후속 개선

사용자 요청으로 작은 반경의 직각 회전에 가까운 후보를 더 넓은 코너링으로 개선했다. [코너링 보고서](results/junction_cornering_20261113/REPORT.md)에 48개 정적 경로 후보, 480회 경로/속도 선택, 1728회 쌍별 동역학 검증을 기록했다. 24개 회전 중 16개는 개발용 참조 후보로 남겼고 8개는 보류했다. 현재 미션에서 허용되는 채택 후보는 14개다.

새 참조는 `teacher_registry.json`의 상태와 실행별 결과 라벨을 함께 사용한다. 일부 후보는 약한 교란에서도 무이탈 자료가 부족하므로 참조 경로 채택을 모든 조건에서의 안전성 인증으로 해석하지 않는다. 전체 후보의 harsh 성적은 악화했으며, 전면 교체나 새 신경망 학습은 수행하지 않았다.

### 코너링 학생 학습 및 검증 파일럿 완료

이후 사용자 승인으로 단계 3~4의 작은 실제 학습을 수행했다. [학습 비교 보고서](results/junction_learning_20261113/REPORT.md)에 교사 96회/51,773프레임, 공통 학생 분기 128개/선호 쌍 31개, CUDA 학습과 최종 폐루프 검증을 보존했다. 기존 direct_v2의 CNN 특징 추출부는 고정하고 특징 투영층·GRU64·출력부 190,050개 파라미터를 학습했다. 전체 CNN 미세조정, 가중치 자동 조정, 전체 미션 시험은 아직 하지 않았다.

같은 초기 가중치와 학습 자료로 모방 loss와 모방+결과 기반 선호 loss를 각각 8 epoch/448회 업데이트했다. 개발 주행으로 선택한 모델은 BC epoch4와 결과 loss epoch8이다. 최종 네 이동×네 교란 조건×세 시드의 48회씩 비교에서 안정 출구는 16→16, 무이탈 안정 출구는 2→10, 심한 이탈은 7→5, 잘못된 출구는 4→3, 시간 초과는 21→24회였다. 약한 복합 교란+강한 조명에서는 안정 출구가 6/12→3/12로 악화했다. 현재 결과로 전반적 우월성을 확인하거나 기존 모델을 교체하지 않는다.

초기화 seed17 한 번의 파일럿이며, 최종 시드 3001/3007/3011은 이제 사용했다. 앞선 기록의 ‘최종 시험 시드 미사용’은 당시 상태다. 다음 개선에서는 별도의 새 시험 시드를 사전 고정해야 한다. 8초 분기 중 잘못된 출구 비용이 발동한 사례는 128개 중 2개뿐이므로, 전체 교차로 종료까지의 결과 라벨과 갱신된 학생의 재수집을 다음 조사 대상으로 남긴다. 이는 확정된 원인이 아니다. 원본 주행 코드 및 기존 모델은 교체하지 않았고 실차 배포도 하지 않았다.
