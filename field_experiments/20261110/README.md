# 2026-11-10 Pi 현장 실행 어댑터 스냅샷

실차 시험에 사용한 `live_outer_trial.py`, `start_threshold_trial.py`의 마지막 상태를 보존한다. 기본 실행은 모터를 연결하지 않는 dry 모드이며, 실제 출력에는 `--drive`가 필요하다. 일반 단위시험에서 이 스크립트를 실행하거나 import하지 않는다.

실행 당시에는 Pi의 별도 폴더에 `drive_v3/`와 두 스크립트를 나란히 두었다. `picamera2`, OpenCV, NumPy, SciPy, gpiozero/lgpio가 설치된 환경을 사용했다. 모터 래퍼는 `/home/pi/straight30/probe.py`의 `Motors`, `read_value`, `safety_reason`에 의존한다. 따라서 이 저장 경로에서 바로 실행할 수 있는 범용 설치 패키지는 아니다. 배포 시 저장소의 `power_diagnostics/probe.py`와 실제 하드웨어 모듈의 일치 여부를 확인해야 한다.

이 어댑터가 사용한 출력은 좌우 두 PWM 채널이다. 네 바퀴 각각의 속도나 회전 여부를 측정하지 않는다. 정지 버튼·전압/온도 상태·0.5초 출력 watchdog·최대 180초 시간 제한이 포함된다. 이는 전원 상실이나 하드웨어 결함에 대한 보장이 아니다.

`--mode world`는 v3 정합/지도 플래너, `--mode local`은 별도 국소 관측 실험 모드다. `--rolling-floor .30`은 30%에서 네 바퀴 모두 출발했다는 단일 현장 관찰에 따른 실험 설정이다. 방향별 모터 속도 전달함수나 코너 부하에서의 최소 출력을 실측한 결과가 아니다. 상한은 60%이며, 요구 회전비를 이 범위에서 만들 수 없으면 정지한다.

현재 기본 출발 초기값은 오른쪽 두 빨간선 사이 구역에서 만들어진다. `--direction ccw`는 위쪽, `--direction cw`는 아래쪽을 바라보는 배치다. 중앙값은 위치 정답이 아니며 배치 범위를 초기 공분산에 반영한다. `--pose`는 별도 재시작 시험용으로 명시한 경우에만 사용했다.

**완주하지 못했다.** local 모드에서 지도 형상·구간 전환·표지판 미션은 완성되지 않았다. 한 바퀴 자동 판정도 이 모드에서는 하지 않는다. 실행 후 원본 이미지·JSONL·설정·코드 해시가 `runs/`에 저장된다. 큰 원본 묶음은 Git에 넣지 않았으며, 결과와 한계는 [현장 기록](../../docs/DRIVE_V3_FIELD_20261110.md)을 참조한다.
