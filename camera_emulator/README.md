# 웹캠 영상의 차 카메라 외형 변환

노트북 전용 도구. 파이 접속이나 모터 제어 기능은 없다. 실시간 웹캠 표시와 학습·시험용 이미지 생성에 같은 변환기를 사용한다.

## 구현 범위

입력 중앙을 4:3으로 자른 뒤 640×480으로 축소하고, 차 카메라의 fisheye K/D를 이용해 왜곡을 추가한다. 이후 Gaussian blur, 밝기 배율, Gaussian noise, JPEG 압축을 적용한다. 차 카메라의 운용 영상처럼 상하가 바로 선 입력을 사용한다. 180도 회전은 자동으로 추가하지 않는다.

포함된 보정은 기존 Claude 파일의 읽기 전용 사본이다. 가상 입력 초점거리를 정해 왜곡 출력의 모든 픽셀에 입력이 대응하도록 구성했다. 이는 실제 웹캠의 시야각이나 카메라 위치를 측정해 맞춘 결과가 아니다. 웹캠 자체의 왜곡은 자동 제거하지 않으며 입력이 이상적인 직선 투영에 가깝다고 가정한다. 정확한 렌즈 모사에는 웹캠 자체 보정이 먼저 필요하다.

기본 blur=1, noise=2, quality=85는 조절 시작값이다. 실제 차 영상으로 최적화한 화질 값이 아니다. 초점의 거리 의존성, 움직임 흐림, rolling shutter, 노면 반사, 자동 노출, 카메라 높이·각도는 재현하지 않는다. 이미 차 카메라에서 받은 영상에 다시 왜곡을 주면 이중 왜곡이 생긴다. 그런 입력의 화질만 바꾸려면 --no-distort를 사용한다.

## 실시간 웹캠

```powershell
cd "C:\workspace\AutoMobile\camera_emulator"
python emulator.py live --camera 0 --output live_session_01
```

왼쪽은 크롭·축소한 입력, 오른쪽은 합성 영상이다. blur/noise/JPEG quality/gain 슬라이더로 조절한다. S는 원본 웹캠 프레임과 합성 이미지 및 설정을 저장하고 Q 또는 Esc는 종료한다. 창의 처리시간은 이 노트북의 현재 처리시간이며 파이 성능이나 센서에서 화면까지의 전체 지연을 뜻하지 않는다. 웹캠 해상도 1280×960은 요청값이며 실제 지원 여부는 기기에 따라 다르다. 카메라를 다른 앱이 사용 중이면 종료 후 실행하거나 --camera 1 등을 지정한다.

실시간 화면은 변환되지만 연속 동영상 녹화 기능은 없다. 녹화한 웹캠 동영상은 batch로 변환할 수 있다. live 출력 폴더도 매번 새 이름을 사용한다.

## 학습 및 시험 자료 생성

```powershell
python emulator.py batch --input "C:\data\webcam_clip.mp4" --output dataset_fixed --sample-fps 2
python emulator.py batch --input "C:\data\webcam_images" --output dataset_aug --randomize --seed 42
```

입력은 이미지 한 장, 동영상 한 개, 또는 이미지/동영상 폴더다. 폴더는 하위 폴더도 읽는다. 동영상은 기본 초당 2장 추출하며 원본 FPS보다 많은 새로운 프레임을 만들지 않는다. 생성 결과는 PNG 이미지, config.json, manifest.jsonl이다. manifest에는 원본 경로·프레임 번호·시간·크롭·실제 적용 설정을 남긴다. 원본 파일과 기존 출력 폴더는 덮어쓰지 않는다.

고정 시험에는 randomize를 끄고 seed와 입력 순서를 고정한다. 학습 증강에서는 blur .4~1.8, noise 0~5, JPEG quality 65~95, gain .85~1.15에서 표본을 뽑는다. 이 범위도 실제 센서 오차 분포가 아니라 가설적인 증강 범위다.

물체 검출 박스나 분할 마스크는 자동 변환하지 않는다. 크롭·리사이즈·왜곡을 적용했으므로 기존 좌표 라벨을 그대로 복사하면 잘못된 학습 자료가 된다. 라벨 변환은 별도 구현해야 한다. 이미지 단위 분류 라벨도 크롭 후 대상이 남는지 확인한다.

같은 영상의 이웃 프레임이나 여러 증강본을 학습/검증 세트에 나눠 넣지 않는다. manifest의 group_id는 원본 파일을 나타내며, 같은 주행을 여러 파일로 쪼갰다면 사람이 주행 단위로 묶어 분할해야 한다. 마지막 평가는 합성 자료만이 아니라 실제 차 카메라 자료로 한다.

## 검증

`python -m unittest discover -s . -p test_emulator.py`

왜곡 매핑의 역변환, 크롭 좌표, 무효과 출력, seed 재현성을 검사한다. 카메라 실기 사용성과 실측 화질 일치도는 별도 확인 대상이다. 실행 의존성은 numpy와 GUI를 지원하는 opencv-python이다.
